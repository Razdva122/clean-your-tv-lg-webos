Выбирайте No-root, если телевизор LG использует Developer Mode. Root подходит только устройству с уже работающим root-доступом и совместимыми службами. Обе редакции Clean Your TV предоставляют один интерфейс Home и работают на телевизоре после установки. Установщик не получает root и не перепрошивает устройство.

## Что требуется для No-root?

No-root использует LG Developer Mode, Key Server и сопряжение по локальной сети во время настройки. Home Helper работает на телевизоре и обрабатывает кнопку Home там, где это поддерживают устройство и прошивка. Оставлять компьютер или телефон включённым для повседневного использования не нужно.

Постоянное условие — активный Developer Mode: продлевайте сессию до её окончания. LG предупреждает, что после отключения режима или истечения сессии приложения, установленные через Developer Mode, могут быть удалены. Автоматическое продление в проекте — необязательная бета-функция, выключенная по умолчанию. Не считайте её гарантией. Перед выбором прочитайте [статью о Developer Mode](/clean-your-tv-lg-webos/ru/articles/lg-developer-mode/).

## Что требуется для Root?

Root использует существующий root-доступ по SSH, совместимые службы телевизора и поддерживаемые возможности ввода и среды выполнения. Сам root-доступ не подтверждает совместимость. Установщик проверяет окружение: не обходите отказ проверки и не заменяйте системную среду выполнения ради установки.

У Root отдельные пакеты и механизм Home. Не включайте Developer Mode поверх уже настроенного root; перед использованием Root отключите No-root Home Helper. Выбор редакции зависит от имеющегося доступа. Кнопка Root в установщике не получает его за вас.

## Как отличаются обслуживание и восстановление?

- **Повседневная работа:** обе редакции запускаются на телевизоре и предоставляют приложения и темы в лаунчере.
- **No-root:** поддерживайте Developer Mode активным, сохраняйте необходимое сопряжение и доступность соединений Home Helper.
- **Root:** сохраняйте независимые службы восстановления и нужную им среду выполнения. Доступность обновлений зависит от установленной редакции и поддерживаемого пути; наличие root само по себе не включает OTA.
- **Аварийный выход:** в актуальных поддерживаемых редакциях это три коротких нажатия Home за две секунды. В Home Helper до 0.6.13 включительно вместо этого использовалось удержание две секунды.

После аварийной остановки постоянное перенаправление включается явным действием. Для No-root откройте Home Helper и выберите Start Helper; для Root используйте Change Home в настройках Home. Смотрите [сравнение редакций](/clean-your-tv-lg-webos/ru/editions/) и [помощь по восстановлению](/clean-your-tv-lg-webos/ru/help/#home-button).

## Что проверить на своём телевизоре?

Откройте [страницу совместимости](/clean-your-tv-lg-webos/ru/compatibility/), зная точную модель, прошивку, webOS и тип пульта. Результаты пользователей относятся к конкретным конфигурациям. После установки отдельно проверьте Home, запуск приложений, звук, ожидание и холодный запуск. Установка пакета не доказывает исправность всех этих сценариев.

Используйте [инструкцию и опубликованный установщик](/clean-your-tv-lg-webos/ru/install/). Если уже есть рабочая установка и вы хотите сменить редакцию, следуйте описанной процедуре перехода и удаления вместо установки поверх другой редакции.
