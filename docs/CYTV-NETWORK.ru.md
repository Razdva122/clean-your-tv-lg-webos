# Куда подключается Clean Your TV

[English](CYTV-NETWORK.md) · [Настройки конфиденциальности телевизора](PRIVACY.ru.md) · [Фильтрация через DNS](PRIVACY-DNS.ru.md)

Для локальной работы выберите встроенную тему, выключите **Настройки → Погода** и закройте приём тем и обоев. Если в вашей редакции доступен совместимый модуль обновлений, при открытии **настроек Home** он может проверить обновления CYTV на GitHub. Когда вы запускаете стриминговое приложение, оно обращается к собственным сервисам.

## Установщик на компьютере и Android

| Действие | Куда идёт запрос и какие данные передаются |
| --- | --- |
| Скачивание CYTV и проверка версии установщика | Файлы и сведения о релизах размещены на GitHub. Перед новой установкой графический или консольный установщик на компьютере проверяет последний стабильный релиз через `api.github.com`, затем читает `BUILD-INFO.json` выбранного релиза на GitHub Releases. Запрос содержит название клиента CYTV. Если проверка недоступна, можно продолжить с имеющимся установщиком. Если выбрать новую версию, откроется страница загрузки. На Android эта проверка версии установщика пропускается. |
| Подготовка Python для совместимого телевизора с Root | Если телевизору нужен отдельный Python, а в кэше установщика нет проверенного архива, установщик загружает закреплённую ARM-сборку из релиза GitHub-проекта `astral-sh/python-build-standalone`, сверяет размер и SHA-256 и передаёт её на телевизор. GitHub может перенаправить загрузку на свои файловые серверы. |
| Поиск телевизора | При автоматическом поиске установщик отправляет SSDP-запрос на групповой адрес `239.255.255.250` по UDP на порт 1900. Имя телевизора он может прочитать из локального HTTP-описания на порту, который указал сам телевизор. При вводе адреса вручную или использовании сохранённого подключения групповой запрос пропускается. |
| Подключение и установка | Пакеты и команды обслуживания идут по SSH на выбранный телевизор. Стандартный TCP-порт Developer Mode — 9922, существующего Root SSH — 22. Порт 22 также применяется для No-root через Root SSH. В Developer Mode Key Server выдаёт зашифрованный SSH-ключ по адресу `http://<телевизор>:9991/webos_rsa`. Используйте доверенную локальную сеть. Перед сохранением подключения проверьте выбранный телевизор и отпечаток его SSH-ключа. |
| Сопряжение и список приложений | По мере необходимости установщик подключается к `wss://<телевизор>:3001` по протоколу SSAP. Подтвердите сопряжение на экране ТВ. Для заполнения Home установщик может прочитать названия приложений, значки и входы. Относительный путь значка запрашивается у того же ТВ по HTTPS на порту 3001 или HTTP на порту 3000. Для Debloat через Developer Mode может понадобиться отдельное сопряжение с правом записи выбранных настроек LG. |

**Debloat** читает и меняет выбранные параметры на телевизоре. Если исходное значение поддерживаемой настройки LG удалось прочитать, установщик записывает его в закрытом профиле для возможного восстановления. Изменение настройки может повлиять на запросы программ LG. Сам Debloat работает через локальное подключение к ТВ. [Настройки установщика](development/INSTALLER-SETTINGS.md)

Установщик хранит на компьютере отдельные профили телевизоров, доверенные SSH-ключи серверов, ключи сопряжения и сведения для восстановления. На Android используется закрытое хранилище приложения. Диагностический отчёт можно экспортировать отдельно. Пока установка или восстановление не завершены, сохраняйте рабочие данные установщика. SSAP использует самоподписанный сертификат телевизора. Пути к каталогам для каждой настольной ОС приведены в [справочнике CLI](CLI.md). Реализация описана в исходниках [поиска](../cytv/discovery.py), [SSH](../cytv/transport.py), [сопряжения](../cytv/tv.py), [проверки версии](../cytv/installer_update.py) и [загрузки Python](../cytv/python_runtime.py).

## Соединения с телевизора

| Возможность | Когда возникают запросы и как ими управлять |
| --- | --- |
| Home и пульт | В Root управление Home идёт через локальные службы webOS. В No-root приложение Helper может подключаться к собственному сетевому адресу телевизора на порту 3001 с сохранённым ключом сопряжения, чтобы отслеживать активное приложение и состояние питания. Плитки, раскладка и счётчики запусков для необязательной сортировки хранятся на ТВ. После выбора плитки начинает работать соответствующее приложение. [Подключение Helper](../native/app/screen-watch.js) · [Список приложений](../launcher/app-library.js) |
| Погода в обеих редакциях | При новой установке погода выключена. Если включить её и выбрать автоматический город, `get.geojs.io` определяет примерное местоположение по публичному IP. Город уточняется не чаще раза в сутки. При ручном поиске `geocoding-api.open-meteo.com` получает текст запроса и язык. Этот сервис также может получить идентификатор города, чтобы вернуть его название на выбранном языке. Для прогноза координаты выбранного города передаются `api.met.no` или `api.open-meteo.com` в обоих режимах. При автоматическом выборе **источника прогноза** возможен переход ко второму сервису при отказе первого. Можно выбрать один источник явно. Выключение погоды останавливает запросы. Город и настройки сохраняются на ТВ, а кэш прогноза может использоваться до шести часов. [Настройки и кэш](development/WEATHER.md) · [Запросы](../launcher/weather-data.js) |
| Обновления CYTV и откат | Совместимый модуль может проверить обновления при открытии настроек Home, раздела **Обновления ПО** или при выборе **Проверить**. Телевизор запрашивает у GitHub сведения о релизе и подписи, а после решения установить обновление — нужные пакеты. Для загрузки возможны перенаправления на `release-assets.githubusercontent.com` или `objects.githubusercontent.com`. По имени запрошенного файла можно определить редакцию, компонент или вариант для конкретного разрешения экрана. Модуль проверяет подпись метаданных и контрольные суммы пакетов. На совместимых телевизорах с Root доступен System Updater, в том числе для No-root через Root SSH. В актуальном No-root через Developer Mode обновление выполняется с компьютера. При откате используются сохранённые на ТВ пакеты и данные профиля. Сохраните их для восстановления. [Варианты обновления](UPDATES.md) · [Проверка обновлений](../launcher/system-updates.js) · [Загрузка в Root](../root-edition/updater/fetch.js) |
| Темы в обеих редакциях | Встроенные и уже загруженные версии тем могут работать без Интернета. При открытии витрины тем или её обновлении Home запрашивает текущую ревизию проекта на `api.github.com`, затем каталог и изображения предпросмотра с `raw.githubusercontent.com`. При загрузке темы запрашиваются файлы из конкретной ревизии репозитория автора. При вводе короткого ID сервис `da.gd` получает этот ID для поиска ссылки. Можно ввести поддерживаемую полную ссылку GitHub и обойтись без сервиса коротких ссылок. Установленные темы хранятся на ТВ. [Управление темами](THEMES.md) · [Обработка ссылок](../launcher/theme-data.js) |
| Личные обои и приём тем | Если открыть **Получить с компьютера** или **Загрузить с телефона**, на ТВ временно включается HTTP-приёмник, обычно на TCP-порту 8879. Компьютер или телефон в локальной сети передаёт тему или фото с помощью PIN-кода с экрана ТВ. Сеанс завершается через десять минут, его также можно закрыть на телевизоре. При загрузке с телефона обрезка и преобразование фото выполняются на самом телефоне. Подтвердите применение на ТВ. Для воспроизведения обоев и поддерживаемой заставки может использоваться внутренний HTTP-адрес телевизора `127.0.0.1` с автоматически выделенным портом. [Приёмник](../theme-receiver/core.js) · [Работа с обоями](development/WALLPAPERS.md) · [Заставка](../screensaver/transport.js) |
| Продление Developer Mode | Необязательная функция в No-root через Developer Mode. После включения телевизор планирует проверки и передаёт действующий токен сеанса Developer Mode серверу `developer.lge.com` по HTTPS, чтобы узнать оставшееся время. Если осталось не более семи дней, он может запросить продление и проверить результат. Отключите автопродление в настройках Home, чтобы остановить плановые запросы. Официальным таймером управляет LG. В Root и No-root через Root SSH продление не требуется. [Логика продления](../renewal-service/renewal.js) · [Запрос к LG](../renewal-service/transport.js) |
| Прошивка LG | Необязательный переключатель Root читает и меняет локальную настройку `blockUpdates` в Homebrew Channel. Homebrew применяет её после полной перезагрузки ТВ. Блокировка может затронуть обновления безопасности и сохраниться после удаления CYTV. Чтобы снять её, выключите блокировку и перезапустите ТВ через Homebrew Channel. Переключатель показывает сохранённый выбор. Доставкой прошивки управляет LG. [Управление обновлениями прошивки](LG-FIRMWARE-UPDATES.md) |

При установке из Homebrew Channel к настроенному репозиторию за пакетом установщика обращается сам Homebrew Channel. Установщик CYTV для Homebrew содержит компоненты для локальной установки. Обновление репозитория в Homebrew и запрос сведений о релизе модулем CYTV выполняются по отдельности. [Способы установки](INSTALL.md) · [Состав пакета Homebrew](../homebrew/payload.py)

## Отчёты, QR-коды и внешние ссылки

**Сохранить диагностический отчёт** записывает локально JSON с уже удалёнными конфиденциальными данными. Отчёт может содержать модель телевизора, доступные версии прошивки, webOS и компонентов, этап операции, результаты проверок и категории ошибок. Стандартный экспорт исключает учётные данные, сетевые адреса телевизора и персональный список приложений. На компьютере можно скопировать редактируемый черновик, открыть GitHub с предложенным заголовком и самостоятельно приложить сохранённый файл. Сохранение отчёта само по себе ничего не публикует. [Как отправить отзыв](FEEDBACK.md) · [Формирование отчёта](../cytv/diagnostics.py)

В установщике Homebrew на ТВ QR-код отчёта открывает на телефоне страницу поддержки проекта на GitHub Pages. Краткий отчёт записан в часть адреса после `#`. Браузер обрабатывает её локально — при первом HTTP-запросе сервер получает адрес страницы без этой части. **Скачать JSON** сохраняет копию на телефоне. Как только вы открываете подготовленное обращение на GitHub, в GitHub передаются заголовок и текст черновика с отчётом. Обращение публикуется после отправки формы. QR-код и полная ссылка содержат копию краткого отчёта. [Формат QR-кода](../homebrew/app/report-format.js) · [Страница поддержки](../website/src/pages/support/homebrew.astro)

Сайт проекта размещён на GitHub Pages. Выбор языка сохраняется в браузере. При переходе по ссылке на загрузку, справку, вход в LG или страницу автора браузер обращается к выбранному сайту. Внешний сервис видит публичный IP, время обращения и запрошенный ресурс. Какие данные он записывает и сколько их хранит, зависит от его правил. В описанных сценариях CYTV список приложений и диагностические данные хранятся локально. Решение поделиться отчётом принимает владелец. Фактический трафик прошивки, сторонних приложений, роутера и браузера зависит от конкретной установки. [Реализация сайта](../website/src/layouts/Site.astro) · [Конфиденциальность ТВ](PRIVACY.ru.md)
