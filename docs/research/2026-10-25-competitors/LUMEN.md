## Do not overstate / useful comparison interpretation

1. Upstream and fork are primarily personalized launchers/ambient experiences. Their device-wide privacy/debloat coverage is much narrower than Glasshouse. Sam's service-stopping notes refer to the separate lasharor/cleanyourtv-WebOS project, not Razdva122/clean-your-tv-lg-webos. Our CYTV does not implement that service debloat; its Root firmware preference is a different feature.
2. Upstream compatibility boundary is important: webOS4.4 issue closed because unsupported, not fixed. xcv58's webOS5 variant is separate, not proof upstream supports Chrome68.
3. A stable IPK can contain implementation awaiting device acceptance. Public release, maintainer own-device observation, reporter confirmation and broad hardware support are distinct evidence levels.
4. Sam's PLAN.md is a working notebook with stale contradictory historical sections: “tag v1.1.0 next” and “not doing background resume” coexist with four published releases and later KeepAlive tests. Prefer exact current source/release + dated results. Do not count unchecked future ideas as shipped.
5. Fork README says “a full week's guide”; exact v1.1.3 source has SCHEDULE_HOURS=8 at line21 and CACHE_HOURS=4 at line30. Use8h in factual comparison and mention discrepancy if needed.
6. Upstream README “no live blur” is also stale against1.1.0/1.1.1 optional live/dock blur release notes. Appropriate statement: preblurred full-screen/canvas backdrops, optional limited blur with explicit performance tradeoff.
7. Sam's public README explicitly says no test suite; preview and TV are its checks. Compare evidence quality carefully: extensive measurement docs exist, but individual performance results can be live injected/local config rather than installed-public-package tests.
8. Two optional native routing methods differ: metadata+setDefaultApp vs installed LG Input Hook vs polling watcher. Do not collapse them into automatic native Home takeover on every firmware.
9. Project names overlap: Gathin23/cleanyourtv and lasharor/cleanyourtv-WebOS are distinct from the CYTV repository used as our baseline here.
