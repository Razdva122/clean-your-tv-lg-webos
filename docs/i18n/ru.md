# Clean Your TV — руководство пользователя

Clean Your TV — ваш домашний экран на LG webOS: приложения в удобном порядке, без рекламных рядов в этом меню. Установите его с компьютера или Android-телефона; после настройки компьютер можно выключить.

## 2. Выбор редакции

Включите ТВ и подключите его и компьютер или телефон к одной домашней сети. При запросе разрешите CYTV доступ к локальной сети.

- **No-root** — если root-доступа нет. Подготовьте Developer Mode по шагам ниже.
- **Root** — если root-доступ по SSH уже есть. Установщик не получает root. Не включайте Developer Mode на таком ТВ; сохраните доступ по SSH и данные восстановления.

Если установщик предложит **No-root**, можно продолжить через существующее подключение SSH от root. Для этого варианта Developer Mode не нужен.

[Подробная инструкция по установке](../INSTALL.md) · [Совместимость](../COMPATIBILITY.md)

### Настройка Developer Mode (No-root)

Developer Mode позволяет CYTV установить приложения на телевизор без root.

1. На телевизоре откройте LG Apps, найдите Developer Mode и установите это приложение.
2. Откройте Developer Mode и войдите в аккаунт LG Developer. Если аккаунта нет, создайте его на [LG Developer](https://webostv.developer.lge.com).
3. Включите Dev Mode Status. Телевизор перезагрузится. После этого снова откройте Developer Mode.
4. Включите Key Server и оставьте Developer Mode открытым. В поле IP Address указан адрес телевизора для ввода в CYTV.
5. Введите Passphrase — код из шести символов на экране Developer Mode на телевизоре. Соблюдайте регистр букв.

Нужен код с экрана ТВ, а не пароль аккаунта LG. Если кода нет, включите Key Server.

Сопряжение — отдельный шаг: когда телевизор покажет запрос, разрешите подключение CYTV с пульта. Если ТВ отклонит запрос, подтвердите повторную попытку в CYTV. Установщик использует то же подключение.

Если подключение к сетевому пульту отклонено, оставьте ТВ включённым и проверьте с компьютера доступ к TCP-порту 3001. Затем выберите **Попробовать снова** в установщике на компьютере.

Если при первой установке No-root появится предупреждение, что не удалось прочитать список входов HDMI, можно продолжить установку с найденными приложениями.

Следите за таймером Developer Mode: до его окончания откройте приложение и нажмите EXTEND при подключённом интернете. Если время истечёт, LG может удалить эти приложения.

## 3. Откройте установщик

- **Windows x64:** скачайте `cytv-windows-x64-desktop.zip`, выберите **Извлечь всё** в Проводнике и откройте `cytv-desktop/cytv-desktop.exe`. Сохраните рядом папку `_internal`.
- **macOS 13+:** распакуйте `cytv-macos-arm64.zip` для Apple Silicon либо `cytv-macos-x64.zip` для Intel. Перенесите `cytv.app` в «Программы» и откройте; разрешите доступ к локальной сети. Если доверенная загрузка заблокирована, используйте «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper.
- **Linux x64:** в Ubuntu 22.04+, Debian 12+ или Mint 21+ установите `cytv-linux-x64.deb` через графический менеджер пакетов, затем откройте Clean Your TV в меню приложений. Для загрузки библиотек может потребоваться интернет. Пакета Linux ARM нет.

**Android ARM64:** нужен 64-битный ARM-телефон с Android 7+ и WebView/Chrome 108+. Откройте скачанный APK и разрешите установку из этого источника, если Android попросит. Запустите CYTV; язык выбирается справа вверху. Обновляйте приложение без удаления и очистки данных.

Оконный мастер сначала выбирает язык системы и сохраняет явно выбранный язык. На телевизоре откройте **Настройки → Язык** и выберите язык либо автоматический вариант, следующий языку телевизора. Настройки языка установщика и телевизора независимы. Все коды приведены в [списке языков](../LANGUAGES.md).

## 4. Установите на телевизор

1. В CYTV выберите **Настроить ТВ**. На компьютере выберите найденный телевизор; на Android введите его IP-адрес. Если поиск не нашёл ТВ, введите адрес вручную.
2. Выберите **No-root** или **Root** и проверьте телевизор перед продолжением.
3. Для No-root введите код с экрана Developer Mode и подтвердите запрос на ТВ. Для Root используйте свои данные SSH; подтверждайте новую SSH-идентичность только для своего ТВ в доверенной сети. Если сохранённый ключ изменился, остановитесь и выясните причину.
4. Следуйте подсказкам мастера. Оставьте ТВ включённым, не меняйте сеть и не закрывайте CYTV до завершения. На Android не останавливайте приложение принудительно.

В оконном установщике после успешной проверки подключения нажмите **Продолжить настройку**: телевизор, подключение и выбранная редакция сохранятся. Мастер объяснит состояние предыдущей установки; технические результаты доступны в **Подробностях**. Если предыдущая операция требует восстановления, сначала выполните предложенное действие восстановления. Перед изменениями мастер проверит установленные версии и запросит подтверждение. Сохранённый запрос перезапуска сначала проверяется заново; мастер просит перезапустить ТВ только по результату текущей очистки.

Если при установке Root предложено заменить текущую интеграцию Home, подтвердите замену, только если хотите восстановить LG Home и продолжить. При отказе останется текущий Home.

При установке Root установщик при необходимости автоматически использует проверенное внутреннее временное хранилище; USB-накопитель не нужен, а если проверка хранилища не пройдена, сохраните данные восстановления и диагностический отчёт.

## 5. Проверьте кнопки пульта

1. Откройте другое приложение на ТВ и коротко нажмите **Home**. Должен открыться Clean Your TV. Укажите в мастере то, что увидели; если проверку не выполняли, оставьте её пропущенной.
2. Проверьте стрелки, OK, Назад, громкость и звук.

<a id="управление-и-восстановление"></a>

## 6. Управление и восстановление

Чтобы обновить среду автозапуска существующей Root Beta, выключите **Change Home** и выполните `cytv migrate-root-beta --edition root --root-variant node012-beta` через сохранённое подключение Root SSH. Приложение и настройки сохраняются. Если предыдущее удаление уже изменило установку, миграция остановится. После завершения включите Change Home и выберите источники автозапуска в настройках Home.

Чтобы открыть штатный центр уведомлений телевизора из Clean Your TV, выберите **Настройки Home → Дополнительно → Уведомления LG**.

Чтобы закрепить HDMI-вход, выберите его в меню **+ / Добавить приложение**. Нажмите OK для переключения на этот вход. Удерживайте OK, чтобы переместить или скрыть плитку.

Стрелки выбирают плитку, OK открывает её; удержание OK позволяет менять порядок. Короткое «Назад» сохраняет навигацию и диалог выхода приложения. Короткое Home открывает наш экран, пока управление Home активно.

Чтобы редактировать плитки короткими нажатиями, откройте **Настройки Home → Внешний вид → Редактировать плитки**. Нажмите OK, чтобы поднять плитку, переместите её стрелками и нажмите OK ещё раз, чтобы поставить. «Назад» отменяет перемещение или завершает редактирование.

Если пульт временно отключился, оставьте управление Home включённым. Когда телевизор снова распознает пульт, управление возобновится автоматически.

**Трижды коротко нажмите Home за две секунды**, отпуская кнопку между нажатиями. Это возвращает LG Home и останавливает управление без сброса настроек.

No-root: Для возобновления откройте Home Helper, выберите «Запустить Helper» и подтвердите. Сохранённый выбор главного экрана не изменится. Root: для возобновления включите **Заменить Home** в настройках Home. **Открыть LG Home** однократно открывает LG Home, не меняя назначение кнопки Home. Чтобы постоянно использовать LG Home, выключите **Заменить Home**. Не запускайте оба обработчика одновременно. При повторном сбое оставьте LG Home активным.

Если Home Helper остановлен, нажмите **Запустить Helper** в настройках экрана Home или заставки. Статус обновится после запуска автоматически.

На телевизорах, где LG Home открывается панелью, включение или выключение **Заменить Home** в Root может ненадолго перезапустить интерфейс ТВ. После перезапуска или сбоя откройте Clean Your TV и снова включите **Заменить Home**, чтобы возобновить управление. LG Home остаётся доступным.

Чтобы освободить место после отката Home, откройте **Настройки → Темы**, выберите **Удалить** рядом с недоступной загруженной темой и подтвердите удаление.

## Нужна помощь?

Если появилось сообщение `ssh-identity-changed`, остановитесь и проверьте ключ SSH телевизора. [Восстановление при смене ключа SSH](../RECOVERY.md#ssh-identity-changed)

Если вы сбросили свой телевизор с No-root до заводских настроек, при сообщении о смене ключа выберите **Переподключить после заводского сброса**. Следуйте подсказкам в доверенной домашней сети. Установщик сохранит прежний профиль и запись удаления.

Если установка на компьютере не завершилась, на экране результата выберите **Проверить варианты восстановления**, а при появлении вопроса **Проверить варианты восстановления?** нажмите **Продолжить**. Мастер использует то же сохранённое подключение к ТВ. Если результат операции с пакетами No-root неизвестен и доступна кнопка **Проверить состояние ТВ**, сначала нажмите её. Предложенное изменение подтвердите отдельно. Если продолжить установку не удаётся, сохраните подключение и данные восстановления.

Если установщик No-root предлагает **Повторить проверку хранилища**, выберите эту кнопку, чтобы повторить проверку без записи на том же телевизоре. После успешной проверки подтвердите установку отдельно. Если установщик найдёт незавершённую операцию, выберите **Проверить варианты восстановления**.

Если установщик на компьютере подтвердил установку пакетов, но кнопка Home не открывает Clean Your TV, на экране результатов выберите **Диагностика кнопки Home** для No-root или **Проверить состояние ТВ** для Root. В No-root откроется уже записанный результат. Чтобы сохранить копию, выберите **Сохранить диагностический отчёт**.

Чтобы сохранить копию на компьютере, на экране результата нажмите **Сохранить диагностический отчёт…**. Если нужна помощь, выберите **Сообщить о проблеме**, проверьте черновик, затем нажмите **Скопировать черновик** и **Открыть форму**. Вставьте черновик и приложите сохранённый отчёт, если он есть.

### Простое удаление

Выберите **Удалить Clean Your TV** в обслуживании с тем же сохранённым подключением к ТВ. Подтвердите один раз. Известные приложения и файлы проекта, которые присутствуют, удаляются; отсутствующие пропускаются, в том числе после частичной установки.

При удалении можно восстановить сохранённые исходные настройки Debloat. Если пропустить восстановление, удаление продолжится без изменения этих настроек.

По запросу отключите питание ТВ, подключите снова, дождитесь подключения к сети. Ожидание и Quick Start не являются полным перезапуском; CYTV не перезапускает ТВ автоматически. Если для очистки нужен Root-доступ, используйте уже настроенное подключение Root к этому же ТВ. Без Root-доступа очистка останется незавершённой. Если ТВ занят, подождите и повторите попытку. Успех показывается только после проверки финальной очистки. Сохраните ключи и исходные отчёты. Аварийное управление и согласие на публикацию выше остаются в силе.

Если установщик на компьютере ждёт ТВ, нажмите **Продолжить удаление**, когда появится эта кнопка. Чтобы прекратить ожидание, нажмите **Отмена**. Чтобы проверить подключение вручную, нажмите **Попробовать снова**.

Если на экране удаления появилась кнопка **Вернуться в LG Home**, нажмите её. Когда установщик подтвердит восстановление, выберите **Продолжить удаление**. При возврате в LG Home прямо из обслуживания приложения остаются установленными.

Если установщик не может проверить удаление, финальную очистку, управление ТВ или результат операции с пакетами либо сообщает об изменении путей проекта, выберите **Проверить варианты восстановления** с исходным сохранённым подключением. Если установщик предложит продолжить, подтвердите это отдельно. Если при восстановлении установки No-root доступна кнопка **Проверить состояние ТВ**, нажмите её и сохраните данные восстановления.

Если установщик не может подтвердить запрошенную полную перезагрузку, сохраните и приложите диагностический отчёт. Сохраните подключение и данные восстановления. Не повторяйте отключение питания снова и снова и не сбрасывайте незавершённую операцию вручную.

Когда установщик на компьютере покажет **Удаление Clean Your TV проверено.**, нажмите **Закрыть**, чтобы завершить работу, или **Настроить телевизор**, чтобы начать новую установку на том же ТВ с той же редакцией и подключением.

**Переустановка Root:** Выберите **Настроить телевизор → Root** с сохранённым подключением и подтвердите **Переустановить Root?**. Установщик восстановит LG Home и полностью удалит Clean Your TV, включая средства обновления, Home Helper и сохранённые настройки. После проверки удаления он установит и активирует пакеты и среду Root из своей сборки. Остальные приложения ТВ и существующий root/SSH-доступ сохранятся. Если оконный мастер остановится, откройте тот же установщик и выберите **Продолжить переустановку Root**. После подтверждения удаления мастер предложит **Продолжить установку Root**. Отдельное действие **Удалить Clean Your TV** никогда не запускает новую установку.

Если во время очистки мастер попросит полностью перезапустить ТВ, отключите телевизор от розетки, подключите снова и включите. После загрузки нажмите **Я перезапустил ТВ — проверить и продолжить**.

### Настройки LG и восстановление после отката Root

В настольном установщике откройте **Обслуживание → Изменить настройки LG (отключение функций)** и используйте сохранённое подключение к ТВ. Отметьте нужные настройки, нажмите **Применить выбранные настройки** и проверьте результаты. Если осталась незавершённая операция, сначала выберите **Проверить варианты восстановления** с её исходным сохранённым подключением.

## Настройки

Если настройка заставки ещё не сохранена, заставка включена по умолчанию. Выключить её можно в разделе **Настройки Home → Заставка**.

В разделе **Настройки → Внешний вид** включите **Часто открываемые**, чтобы приложения, которые вы чаще запускаете, поднимались в сетке. Порядок в доке сохраняется. Удерживайте OK, чтобы перейти к ручному порядку для перемещения плитки или переноса её к урне. Выключите параметр, чтобы вернуться к ручному порядку. Эту настройку также можно выбрать в конце шага «Настройки» в установщике cytv.

Выбирайте раздел кнопками ↑ ↓ и переходите в него кнопкой → или OK. ← возвращает к разделам; кнопка «Назад» сначала возвращает к ним, затем закрывает настройки. При возвращении в раздел фокус сохраняется на последнем доступном элементе. В «Столбцах» стрелки соответствуют сетке из трёх колонок. В «Языке» фокус попадает на выбранный язык.

В разделе **Настройки → Ваш экран Home → Формат времени** выберите **Авто (по локали ТВ)**, **12 часов** или **24 часа**.

В No-root настройка **Настройки → Ваш экран Home → Оставлять HDMI и эфирное ТВ при пробуждении** оставляет открытым HDMI, эфирное ТВ или другой вход, если телевизор уже показывает его после выхода из режима ожидания. По умолчанию параметр выключен. Кнопка Home работает как обычно.

Если No-root не может прочитать статус Home, нажмите «Повторить». Недоступный переключатель не означает, что управление Home выключено. В «Обоях» можно загрузить изображение с телефона или CYTV; качество и затемнение доступны после выбора обоев. Удаление личных обоев требует подтверждения; «Отмена» сохраняет их.

## Погода

Откройте Настройки → Погода, под Обоями. Если город не сохранён, Home определяет его по интернет-соединению при включённой погоде. Чтобы указать город самостоятельно, откройте «Город» → «Вручную», найдите город и выберите нужные регион и страну. VPN может изменить результат; если город не определился или указан неверно, используйте поиск. Определённый или выбранный город виден в настройках. Выберите °C / м/с или °F / мили/ч и доступный формат: Краткий, Сейчас, Подробно или На 4 дня. Превью учитывает тему; пометка «Пример» означает демонстрационные данные. Liquid Glass поддерживает только краткий формат. В Ribbon и Atmosphere погода недоступна. Выключение погоды прекращает запросы и скрывает выбор города, единиц и формата; выбор источника остаётся доступным. При сбое связи недавние данные могут временно оставаться на экране; после длительного сбоя погода скрывается до обновления.

Выберите источник прогноза: Auto, MET Norway или Open-Meteo. Auto сначала обращается к MET Norway, при сбое один раз пробует Open-Meteo, затем использует последний успешный источник и кэш. При ручном выборе источник автоматически не меняется. Новые настройки используют Auto; ранее сохранённые без источника сохраняют Open-Meteo. Фактический источник виден в настройках. Доступность зависит от сети. MET обновляется не чаще раза в три часа; кэш хранится не более шести часов. Отсутствующие поля скрыты: MET не предоставляет температуру «ощущается как» и вероятность осадков. Суточные диапазоны рассчитаны по точкам прогноза, а не по измеренным экстремумам.

Координаты прогноза отправляются на api.met.no или api.open-meteo.com, поисковые запросы городов — на geocoding-api.open-meteo.com. Необязательное автоматическое определение города передаёт публичный IP на get.geojs.io. Соединения используют HTTPS; ключ API не нужен. Местоположение, источник и кэш сохраняются на ТВ. В «Источниках данных» приведены условия и авторство, включая Норвежский метеорологический институт (MET Norway, CC BY 4.0).

Кнопка «Источники данных» в заголовке раздела «Погода» открывает сведения о сервисах и лицензиях.

## Обои с iPhone

Откройте Настройки → Обои → Загрузить с телефона и отсканируйте код. Выберите JPG, PNG или HEIC/HEIF, кадрируйте фото, подтвердите ограничение качества и отправьте. На ТВ выберите Применить. Safari использует встроенную поддержку HEIC; Chrome, Firefox и другие современные браузеры при необходимости — включённый локальный декодер. Преобразование идёт на телефоне без внешнего сервиса. Отмена или выбор другого файла останавливает его. Вход: 32 МиБ и 50 миллионов пикселей; выход: до 1080p и 2 МиБ. При ошибке выберите другое фото или JPG/PNG. Это относится к странице телефона, не приложению Mac.

## Настройка вашего Clean Your TV

Перед выбором темы на шаге **Отключение функций LG** выберите, какие настройки рекламы, рекомендаций, приватности и уведомлений LG хотите изменить. В графическом установщике пункты рекламы, рекомендаций, приватности и уведомлений выбраны по умолчанию. Снимите лишние галочки перед нажатием **Продолжить**. Проверьте результат по каждому пункту. Если исходное значение не удалось прочитать, установщик не сможет сохранить его для автоматического отката. Чтобы оставить настройки ТВ как есть, нажмите **Пропустить этот шаг**.

В обеих редакциях можно отключить рекламные трансляции LG, если телевизор предоставляет эту настройку.

Чтобы отменить одно изменение, откройте «Отключение функций LG» в разделе обслуживания с тем же сохранённым подключением к ТВ. Выберите настройку, проверьте исходное значение и подтвердите восстановление. Для отключения автозапуска LG Channels на поддерживаемых моделях откройте «Все настройки → Общие → Каналы → Автозапуск LG Channels» и выберите «Выкл.».

После успешной установки выберите Classic, Liquid Glass или Ribbon и включите либо выключите погоду на главном экране. Ribbon не поддерживает погоду; Liquid Glass использует краткий формат. Город определяется приблизительно по интернет-соединению; его можно изменить в настройках Home.

No-root через Developer Mode предлагает автопродление; продолжайте следить за официальным таймером. При новой установке No-root через существующий root SSH вкладка Developer Mode скрыта. В Root доступна блокировка обновлений прошивки LG через Homebrew Channel, включая обновления безопасности; нужен настоящий перезапуск через Homebrew Channel. Обновления CYTV управляются отдельно.

Кнопка «Сохранить текущие настройки» пропускает настройку. Переключатель функции режима показывает её текущее состояние. Если его не менять, настройка сохранится. Переустановка Root по-прежнему удаляет сохранённые настройки CYTV, как описано выше. Проверьте оформление на ТВ; если дополнительная настройка не подтверждена, проверьте её в Home перед повтором.

## Обновления на телевизоре с root

Если настроен System Updater с самообновлением, используйте **Обновление ПО → Обновить всё** для Root или No-root на телевизоре с root. Не выключайте телевизор до завершения. Чтобы восстановить только обновлятор, откройте Home и выберите **Обновление ПО → Восстановление → Переустановить System Updater**: Home и ваши настройки сохранятся. Для No-root без root по-прежнему нужен способ установки через компьютер.
