## Выбор редакции

No-root и Root — равноправные варианты для разных конфигураций телевизора. Выбирайте No-root для LG Developer Mode или Root при уже имеющемся root-доступе по SSH. Совместимость и объём проведённых проверок зависят от версии.

- **No-root:** включите LG Developer Mode и Key Server. Введите кодовую фразу с экрана телевизора и отдельно подтвердите на телевизоре запрос сопряжения. Developer Mode должен оставаться активным: после истечения сессии установленные таким способом приложения могут удалиться. Следите за официальным таймером даже при включённом продлении Beta. Для мониторинга Helper нужна локальная сеть.
- **Root:** требуется уже работающий root-доступ по SSH. Установщик не получает root. Не включайте Developer Mode поверх существующей root-конфигурации. Сохраняйте доступ по SSH и работоспособность служб восстановления.

Для Root нужны рабочие интерфейсы Home в Settings Service и System Profile (`com.webos.service.systemprofile`); одного наличия root-доступа недостаточно для совместимости.

> **1.6.0:** Root проверяет необходимые интерфейсы Home до подготовки приватного Python и пакетов. Ошибка останавливает установку; успешная проверка не доказывает совместимость прошивки или работу кнопки Home. Для известных ошибок подключения есть отдельные подсказки. Сохраняйте профиль, доверенные ключи и данные восстановления; незавершённая операция требует проверенного восстановления, а не повторной установки вслепую. Сохраните и проверьте диагностический отчёт. [Подробнее](../development/INSTALLER-PREFLIGHT-HELP.md).

## Перед установкой

Включите телевизор и подключите компьютер к той же доверенной локальной сети. После установки компьютер можно выключать. Совместимость зависит от модели, прошивки и пульта; для Root остаются незавершённые проверки на оборудовании.

1.5.4 включает Home Helper **0.6.21** для TV Node.js **0.10.25+**; Root по-прежнему требует Node.js **8+**. [Compatibility](../COMPATIBILITY.md).

No-root Helper нужен Node.js **0.10.25+** на ТВ. Root нужны Node.js **8+** и рабочий Python **3.9+**. При необходимости установщик скачает проверенный частный Python; для первоначальной подготовки нужно **320 MiB** свободного места. Системный Python не заменяется. Сохраняйте версии среды, нужные восстановлению. [Python (англ.)](../OPTIONAL-PYTHON.md). Автопродление Developer Mode — **Beta, по умолчанию выключено**. Реальное продление на ТВ без root не подтверждено; проверяйте официальный таймер.

### Настройка Developer Mode (No-root)

Developer Mode позволяет CYTV установить приложения на телевизор без root.

1. На телевизоре откройте LG Apps, найдите Developer Mode и установите это приложение.
2. Откройте Developer Mode и войдите в аккаунт LG Developer. Если аккаунта нет, создайте его на webostv.developer.lge.com.
3. Включите Dev Mode Status. Телевизор перезагрузится. После этого снова откройте Developer Mode.
4. Включите Key Server и оставьте Developer Mode открытым. В поле IP Address указан адрес телевизора для ввода в CYTV.
5. Введите Passphrase — код из шести символов на экране Developer Mode на телевизоре. Соблюдайте регистр букв.

Нужен код с экрана ТВ, а не пароль аккаунта LG. Если кода нет, включите Key Server.

Сопряжение — отдельный шаг: когда телевизор покажет запрос, разрешите подключение CYTV с пульта.

Следите за таймером Developer Mode: до его окончания откройте приложение и нажмите EXTEND при подключённом интернете. Если время истечёт, LG может удалить эти приложения.

## Установка и язык

- **Windows x64:** скачайте `cytv-windows-x64-desktop.zip`, выберите **Извлечь всё** в Проводнике и откройте `cytv-desktop/cytv-desktop.exe`. Сохраните рядом папку `_internal`. Подпись издателя Windows не настроена. Отдельная консольная версия — `cytv-windows-x64.exe`; переименуйте её в `cytv.exe` и используйте `.\cytv.exe` в PowerShell для команд ниже.
- **macOS 13+:** распакуйте `cytv-macos-arm64.zip` для Apple Silicon либо `cytv-macos-x64.zip` для Intel. Перенесите `cytv.app` в «Программы» и откройте; разрешите доступ к локальной сети. Если доверенная загрузка заблокирована, используйте «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper. Проверка старых систем не завершена.
- **Linux x64:** в Ubuntu 22.04+, Debian 12+ или Mint 21+ установите `cytv-linux-x64.deb` через графический менеджер пакетов, затем откройте Clean Your TV в меню приложений. Для загрузки библиотек может потребоваться интернет. Пакета Linux ARM нет. Отдельный исполняемый файл `cytv-linux-x64` — это CLI; для оконного приложения нужен `.deb`.

[Установщик Android (англ.)](../../android/README.md): язык выбирается справа вверху. Обновляйте без удаления приложения и очистки данных. Android 7 / WebView 108 — минимум, а не проверенный телефон; приёмка выполнена в эмуляторе Android 15 ARM64 / WebView 124. Физические телефоны и восстановление при реальном подключении к ТВ не проверены.

Оконный мастер сначала выбирает язык системы и сохраняет явно выбранный язык. На телевизоре откройте **Настройки → Язык** и выберите язык либо автоматический вариант, следующий языку телевизора. Настройки языка установщика и телевизора независимы. Все коды приведены в [списке языков](../LANGUAGES.md).

Для отдельно скачанной CLI в macOS/Linux откройте терминал в распакованной папке:

```sh
chmod +x cytv
./cytv --language ru install
```

Выберите телевизор или введите его IP, выберите редакцию и проверьте итоговые параметры. Подтверждайте новую SSH-идентичность только для своего телевизора в доверенной сети; изменение сохранённого ключа блокирует подключение. Root подготавливает восстановление и сразу активирует Home, без пробного периода и подтверждения сохранения. Проверьте стрелки, OK, Home, Назад/Отмена, громкость, выход из ожидания и запуск после полного отключения питания.

В 1.6.0 отдельно показаны проверка пакетов, состояние запуска и ваше наблюдение за физической Home. Подтверждение запуска или обнаружение процесса Helper не доказывает перехват Home. Откройте другое приложение на ТВ, один раз коротко нажмите Home и укажите результат; по умолчанию выбрано **Не проверял / пропустить**. `--yes` не отвечает за вас, а неинтерактивная установка оставляет проверку невыполненной. Ошибка Home или пропуск не отменяют установку пакетов и не запускают переустановку. Для помощи сохраните локальный отчёт; он не публикуется автоматически. Другие кнопки, звук, ожидание и холодный запуск проверяются отдельно.

## Управление и восстановление

Стрелки выбирают плитку, OK открывает её; удержание OK позволяет менять порядок. Короткое «Назад» сохраняет навигацию и диалог выхода приложения. Короткое Home открывает наш экран, пока управление Home активно. Удержание «Назад» в течение 1,2 секунды однократно открывает LG Home. Переключатель управления Home и ваши настройки не меняются.

**Трижды коротко нажмите Home за две секунды**, отпуская кнопку между нажатиями. Это возвращает LG Home и останавливает управление без сброса настроек. В старом No-root Helper до версии 0.6.13 включительно вместо этого удерживайте Home около двух секунд. Удержание Home не является аварийным жестом Root.

No-root: Для возобновления откройте Home Helper, выберите «Запустить Helper» и подтвердите. Сохранённый выбор главного экрана не изменится. Root: для возобновления включите **Заменить Home** в настройках Home. **Открыть LG Home** однократно открывает LG Home, не меняя назначение кнопки Home. Чтобы постоянно использовать LG Home, выключите **Заменить Home** или выполните `cytv restore`. Не запускайте оба обработчика одновременно. При повторном сбое оставьте LG Home активным.

> **1.5.4 — Root:** явное включение **Изменить Home** при исправном Root создаёт собственный нативный вход **Clean** и сохраняет его как запомненный вход. Выключение управления Home, аварийная остановка, сбой, приостановка для обновления или удаление убирает запись CYTV. Прежний запомненный вход восстанавливается, только пока текущее значение остаётся установленным CYTV; чужие входы и приложения на переднем плане сохраняются. На неподдерживаемом ТВ или при чужой записи остаётся обычное защищённое управление Home. Немедленный первый экран Clean не гарантируется. Записанные проверки первого экрана, ожидания и холодного старта после отключения AC на C3 прошли; это не универсальная совместимость. После обновления/отката Home может остаться выключенным (#202), а настройки показывать старое состояние (#206): закройте и откройте настройки, явно включите «Изменить Home» и дождитесь статуса Clean. [1.5.4 QA (English)](../history/2026-10-31-release-1.5.3-signed-root-qa.md) · [Native input (English)](../development/ROOT-NATIVE-INPUT.md).

```sh
./cytv --language ru status
./cytv --language ru doctor --report
./cytv --language ru restore
./cytv --language ru uninstall
```

> **1.6.0 (#152):** при отказе отключения Helper восстановление/удаление No-root сможет использовать проверяемую остановку по SSH. Стоп-маркер сохраняется; при неопределённом результате журнал остаётся. Не удаляйте файлы состояния. Проверка на EF950V ещё нужна. [#152](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/152)

> **1.6.0 (#201):** проверка No-root сохраняет журнал прерванной установки или удаления. Совпадение файлов или отсутствие приложений не доказывает завершение операции. Если проверка отклонена, остановитесь и сохраните диагностику; обхода только по файлам нет. [#201](../RECOVERY.md#unreleased-uncertain-no-root-package-operations-201)

После прерывания сначала выполните `status` и сохраните журналы. `restore` возвращает LG Home без удаления приложений; `uninstall` восстанавливает его перед удалением. Данные восстановления Root намеренно остаются: не удаляйте их ради принудительной переустановки. Перед отправкой проверяйте диагностические отчёты; не публикуйте ключи и папки профилей.

Откройте **Настройки Home → Внешний вид → Столбцы** и выберите от 1 до 8 столбцов или **Как в теме**, чтобы использовать значение темы (для Classic по умолчанию 5). Явно выбранное число имеет приоритет над темой. В темах с фиксированной компоновкой пункт «Столбцы» скрыт и используется значение автора. Сохранённый выбор вернётся при переходе на тему, которая поддерживает эту настройку. В загруженной теме Alpine приложения расположены в одной бесконечной горизонтальной ленте: влево/вправо прокручивают её по кругу, вверх открывает быстрые кнопки, вниз возвращает к тому же приложению. В Alpine ленту также можно прокручивать колесом мыши или тачпадом; за открытым диалогом Home не прокручивается.

1.5.4: **Настройки Home → Внешний вид** и выключите **Показывать плитку «Добавить приложение»**, чтобы скрыть +. По умолчанию она включена. Через **Добавить приложение** в том же разделе можно добавлять и возвращать приложения, даже когда + скрыт. Перемещение и скрытие приложений остаются доступны; выбор сохраняется после перезапуска. Если скрыть все приложения, верхние кнопки и настройки останутся доступны.

Не выпущено: выбранная тема задаёт меню **Входы** в шапке или полку HDMI; общей настройки расположения и переключателя **Показывать входы на Home** нет. Полка пока поддерживается только в `dock-grid`. Liquid Glass включает её; Classic и темы без этой опции сохраняют меню в шапке. На полке вверх из дока переходит к входам, ещё раз вверх — к шапке, вниз или Back возвращает в док, OK запускает источник. Если есть плитки источников, полка заменяет меню входов в шапке. Имя устройства берётся из метаданных EIM, только если прошивка их передаёт; иначе подключённый источник показывает **Подключено**. Home не придумывает имя PlayStation и не гарантирует определение по CEC. Пустые порты остаются доступными для выбора. Превью **выключены по умолчанию**. Явно включите **Настройки Home → Внешний вид → Предпросмотр выбранного входа**, чтобы видеть подключённый HDMI примерно через 0,8 секунды фокуса, только пока тема использует полку. На некоторых ТВ превью HDMI могут воспроизводить звук или включать HDR; тишина не гарантируется. Home не меняет автоматически общую настройку отключения звука ТВ или HDR. Live TV и пустые порты сохраняют обычные плитки.

В превью тем версии 1.5.4 с боковой панелью стрелки вверх/вниз выбирают пункт меню, стрелка вправо переводит к приложениям, а стрелка влево из первого столбца приложений возвращает в меню.

No-root 1.5.0: Helper может восстановиться после временного тайм-аута watchdog при выходе из ожидания, не более пяти попыток за десять минут. Stop и тройное Home по-прежнему требуют явного запуска Helper; повторяющиеся сбои оставляют его остановленным. Приёмка на ТВ ещё не выполнена. [Поведение и ограничения (англ.)](../HELPER-DIAGNOSTICS.md#watchdog-recovery-unpublished-candidate-155).

## Обновление и удаление

Храните рабочие пакеты и личные резервные копии настроек. При замене пакетов No-root с компьютера сначала остановите Helper и обновляйте без удаления: оно может стереть настройки. Удаление приложения с компьютера не удаляет приложения ТВ. Не ставьте отдельную IPK поверх работающей среды Root; используйте предусмотренный процесс восстановления или переустановки cytv.

Откройте настройки Home → Обновление ПО, проверьте версии и подтвердите действие. Обновление и откат с ТВ требуют **root, Homebrew Channel** и подготовленных совместимых обновляторов, даже для редакции No-root. Без root используйте компьютер. Подготовка полного системного обновления — отдельное явное действие: [обновления (англ.)](../UPDATES.md). Сохранённая версия отката видна в разделе восстановления; последующие изменения настроек могут потеряться.

**Если установлена 1.3.0:** исходный System Updater может отклонить изменённую инфраструктуру. Сохраните незавершённую операцию и следуйте проверяемому восстановлению и подготовке замены, описанным для 1.5.0+; не удаляйте журналы и не повторяйте вслепую. Обновление одного приложения не заменяет закреплённую инфраструктуру Root. [Переход и восстановление (англ.)](../UPDATES.md#one-time-computer-preparation).

Исправление канала настроек Home выпущено в 1.5.0. Обновляйте Home и Helper вместе согласованным опубликованным установщиком; обновление только Home не меняет Helper. Приёмка остаётся ограниченной указанными моделями. [#146](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/146).

Восстановление звука HDMI в Root экспериментальное и **по умолчанию выключено**; включайте только при необходимости. Оно может прерывать исправный звук и не подтверждает совместимость eARC. [Восстановление звука (англ.)](../development/ROOT-AUDIO-RECOVERY.md). Отдельный **CYTV Installer для Homebrew ещё не выпущен**; используйте опубликованный установщик для компьютера или Android.

Homebrew Channel запретил доступ этому установщику. На webOS 11 для Homebrew 0.7.3 требуется исправление совместимости от его разработчиков. Пока оно не войдёт в поддерживаемый выпуск Homebrew, используйте опубликованный установщик для компьютера или Android. [#116](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/116).

1.5.0+: если доступ к API прошивки запрещён из-за старых прав каталогов Root, явная команда `cytv enable-firmware-access --edition root --repair-package-permissions` сверяет текущий пакет с доверенными личными данными и убирает запись для группы и остальных только на собственных путях Root. Неизвестные или изменённые файлы останавливают ремонт. Профиль, выбор Home и настройка блокировки прошивки сохраняются; [подробнее о ремонте (англ.)](../LG-FIRMWARE-UPDATES.md#explicit-package-permission-repair-candidate).

1.5.0+: `cytv recover-system-rollback --edition root` предназначена для проверенного отката Root, когда все установщики пакетов завершились, но истёк срок готовности лаунчера. Требуется настоящий сигнал готовности лаунчера; неизвестные результаты установки блокируют восстановление. Пакеты, закреплённый код и ключи, свидетельства сбоя и явно выключенное управление Home сохраняются. Ограниченная попытка записывается в частный журнал. Обычный повтор не продлевает срок попытки. Только после истечения прежних 120 секунд, без принятого сигнала готовности и неизвестного результата установки, `--new-recovery-attempt` архивирует весь прежний журнал по UUID/хешу и явно открывает новую попытку. Завершённое восстановление остаётся идемпотентным; автоматической цепочки повторов нет. [Порядок и ограничения (англ.)](../RECOVERY.md#root-system-rollback-readiness-candidate).

1.6.0: System Updater 1.2.0 предназначен для допустимой новой установки или проверенной замены 1.1.0/1.1.1 командой `cytv replace-system-updater --edition root`. Меняется только System Updater; приложения Root/Root Updater, полный профиль и выбор Home сохраняются, старое состояние архивируется. Неизвестные или незавершённые операции блокируют замену. Установленный 1.1.2 остаётся закреплённым на старых каналах; общего пути миграции нет. Не форсируйте замену. Это не ограничивает каналы No-root. [Порядок замены (англ.)](../RECOVERY.md#replace-the-root-system-updater-candidate)

## Помощь и подробные инструкции

В 1.6.0 выберите **Проверить варианты восстановления** для того же сохранённого ТВ или выполните `cytv recover`. Проверка и изменения требуют отдельных подтверждений с выбором «Нет» по умолчанию; `--yes` их не разрешает. Root продолжает работу только после существующих проверок. No-root предлагает удаление лишь при разрешении существующей проверки службы пакетов; удаление может сбросить настройки Home. Новая установка не начинается автоматически. При неизвестном состоянии или отказе доступа сохраните отчёт и остановитесь; сохраняйте журналы и не повторяйте удаление. Это не устраняет нехватку доказательств завершения в #201 и не подтверждает восстановление ТВ из #216. [Recovery](../RECOVERY.md). Для помощи укажите модель, прошивку, редакцию, версию установщика, шаг ошибки, ожидаемый и фактический результат; перед отправкой проверьте отчёт и удалите секреты.

Не выпущено: восстановление может продолжить удаление No-root, остановившееся до первого запроса удаления пакета, без доступа к общему статусу установщика, если это подтверждает исходный журнал. Подтвердите удаление отдельно; после проверенного удаления запустите установку отдельно. Неизвестные и уже отправленные операции по-прежнему блокируют продолжение; сохраните подключение и журналы. В 1.6.0 этого изменения нет. [Подробнее](../RECOVERY.md#no-root-removal-stopped-before-package-submission-unreleased).

[Документация](../README.md) · [Сообщить о проблеме](../FEEDBACK.md)

В разработке: если запросы удаления пакетов ещё не отправлены, после сбоя доступно **Проверить варианты восстановления** для того же сохранённого ТВ. Проверка и удаление требуют отдельных подтверждений. При отказе проверки состояния пакетов восстановление останавливается и предлагает отчёт. Его раздел `recovery` различает не начавшееся удаление, унаследованную операцию и прерванную работу с пакетами без публикации полного журнала; этот раздел не разрешает восстановление.

## Темы

Кандидат 1.7.0: **Настройки → Темы**. **Classic**, **Liquid Glass**, **Ribbon** встроены и не требуют загрузки темы; по умолчанию выбрана Classic. **Channel** — внешняя тема из showcase. При пробе в витрине: Выберите тему и нажмите **Оставить тему** за **20 секунд**. **Вернуть прежнюю**, Back или истечение времени восстановят прежнее оформление. Если закрыть Home во время неподтверждённой пробы, следующий запуск вернёт Classic. Встроенные и загруженные темы в списке установленных применяются и сохраняются сразу, без таймера подтверждения. Темы с компьютера и по URL также выбираются без таймера. Только «Попробовать тему» внутри витрины запускает пробу на 20 секунд.

1.7.0: встроены **Classic**, **Liquid Glass** и **Ribbon**. **Alpine 1.4.4** переносится в загружаемые темы **витрины тем**. Сохранённый выбор `builtin:alpine` возвращается к Classic с существующим видимым уведомлением о восстановлении; Home не скачивает Alpine автоматически и не заменяет её на Liquid Glass. В опубликованную версию 1.6.0 входят Classic, Alpine и Ribbon.

Установленные темы расположены в одной горизонтальной строке с прокруткой. Активная тема всегда первая, её карточка выделена фоном и рамкой. Для перехода по строке используйте влево/вправо.

Витрина показывает только темы, которых нет на этом ТВ. Classic, Liquid Glass, Ribbon и загруженные темы скрыты, даже если в каталоге есть более новая версия. После удаления загруженная тема снова появится в витрине. Обновляйте тему через «Добавить по ID» или «Получить с компьютера».

Карточки тем встроены прямо в «Темы», рядом с категориями настроек. Витрина, установка по ссылке и получение с компьютера открываются в этом же разделе; только пробное применение из витрины временно показывает Home.

При открытии витрины тем или выборе «Обновить» каталог проверяется в основном репозитории проекта без обновления Home и перезагрузки страницы. Новые записи доступны после обычного слияния; до слияния кандидата может показываться встроенный каталог. Без сети или при ошибке используются встроенные записи и превью. Встроенные темы соответствуют установленной версии Home. Откройте превью Channel и выберите **Скачать тему** (нужен интернет). После загрузки попробуйте тему и нажмите **Оставить тему** за **20 секунд**. Установленные темы работают без сети. **Добавить по ID** по-прежнему принимает закреплённые ссылки.

Для проверки неопубликованной темы сначала откройте на ТВ **Настройки → Темы → Получить с компьютера**. Введите показанные телевизором адрес ТВ и шестизначный PIN в **Send to TV** в превью на компьютере, отправьте тему и нажмите **Применить тему** на ТВ. Основной способ использует исходящее подключение ПК к порту **8879 на ТВ**, без изменения брандмауэра компьютера. Оба устройства должны быть в одной доверенной домашней сети. Приёмник закрывается после одной загрузки, отмены, выхода из раздела или через **10 минут**. PIN не сохраняется; установленная тема работает без сети. Публикация в GitHub не нужна.

Для опубликованной темы откройте **Добавить по ID** и введите ID (например, `102300a209`), `da.gd/102300a209` или полную ссылку GitHub. Перед загрузкой Home покажет развёрнутый адрес da.gd, затем проверит назначение GitHub и пакет темы. Автор может дать ID из описания релиза или кнопки **TV link → Copy ID** в превью на компьютере.

**1.6.0:** **Показать диагностику** в панели Home Helper показывает небольшой отфильтрованный результат её собственных запросов состояния. Просмотр не запускает Helper и не меняет управление Home. По запросу отправляйте только проверенный JSON; [подробнее](../HELPER-DIAGNOSTICS.md#candidate-panel-caller-diagnostics-207).

[Themes (English)](../THEMES.md) · [1.5.4 QA (English)](../history/2026-10-31-release-1.5.3-signed-root-qa.md).

В настраиваемых ленточных темах 1.5.4 маленькие кнопки входов, Wi-Fi и настроек могут находиться слева внизу. Если тема включает такую навигацию, влево от первой видимой карточки выбирает настройки, затем Wi-Fi и входы; вправо из настроек возвращает к той же видимой карточке. На неподдерживаемой версии Home установка темы с новой необходимой возможностью отклоняется, сохраняя текущий вид и выбор темы. Сначала обновите Home. Понижение версии после выбора такой темы может вызвать восстановление Classic при запуске.

В разделе «Темы» показаны превью встроенных и всех установленных вами тем, в том числе без интернета. Отдельная кнопка «Витрина тем» открывает опубликованный каталог; личная установка не публикует тему.

Во «Внешнем виде» находятся «Столбцы» с текущим количеством, показ плитки «Добавить приложение» и добавление приложений. В отдельной категории «Темы» находятся установленные темы, витрина, получение с компьютера и «Добавить по ID» справа. Основной способ добавления — ID темы, например 102300a209. Classic возвращается выбором её карточки; загруженные темы удаляются по отдельности. В категории «Язык» выбор доступен сразу, без дополнительного окна.

В браузерном превью пункт «Получить с компьютера» показывает действия для телевизора и не запускает приёмник ТВ на компьютере. Используйте Send to TV над превью. Удаление загруженной темы требует подтверждения; перед удалением активной темы восстанавливается Classic. Отмена сохраняет тему.

## Категории настроек (1.5.4)

В обеих редакциях категории расположены слева, настройки выбранного раздела — справа: «Ваш главный экран», «Внешний вид», «Темы», «Язык», «Обновление ПО» и «Дополнительно». В No-root также есть «Режим разработчика»; в Root обновления прошивки LG находятся в разделе обновлений, а HDMI-звук — в дополнительных настройках. Вверх/вниз перемещают фокус внутри колонки, вправо открывает настройки категории, влево возвращает к категориям. «Назад» сначала возвращает к категориям, затем закрывает настройки. Кнопка возврата на главный экран также доступна через Tab.

Жёлтый кружок у категории «Обновления ПО» и у вложенной кнопки означает, что доступно обновление. Оба индикатора исчезают, когда успешная проверка подтверждает отсутствие обновления; при ошибке проверки сохраняется последнее подтверждённое состояние.
