# Clean Your TV — руководство пользователя

Clean Your TV — ваш домашний экран на LG webOS: приложения в удобном порядке, без рекламных рядов в этом меню. Установите его с компьютера или Android-телефона; после настройки компьютер можно выключить.

**v1.12.1 — В следующем выпуске (ещё не опубликовано):** При сбое подключения установщик объяснит запрет сетевого доступа, отказ SSH-порта или таймаут. **«Проверить подключение снова»** запускает диагностику без установки пакетов; **«Изменить подключение»** позволяет проверить новые параметры. На macOS кнопка **«Открыть системные настройки»** помогает найти доступ к локальной сети; там может отображаться имя старой копии. Незавершённые операции сохраняют свой сценарий восстановления.

<a id="неопубликованный-кандидат-unreleased-старый-nodejs-на-тв"></a>

## Старый Node.js на ТВ (опубликовано в v1.12.0)

Эти варианты включены в опубликованный выпуск v1.12.0. Если обычный Root отклоняет версию Node.js на ТВ (нужен Node.js 8+), установщик может предложить **No-root через имеющийся root SSH**: Home и Home Helper без установки Developer Mode. Никогда не включайте Developer Mode поверх имеющегося root. Только при **точной версии Node.js 0.12.2** дополнительно доступен **Root Beta** с отдельными пакетами и явным подтверждением. Системный Node.js не заменяется; автоматических/OTA-обновлений нет — используйте установщик на компьютере. **No-root — урезанный функционал**: нет системного перенаправления Home и функций управления, доступных только в Root. **Root Beta — ещё недостаточно протестирована** на телевизорах.

Остальные проверки нативных компонентов, интерфейсов Home и Python остаются обязательными. Физические проверки под наблюдением владельца ещё не выполнены; совместимость не заявляется. Сохраните диагностический отчёт, отметьте непроверенные пункты и при желании вручную поделитесь результатом без личных данных по [руководству обратной связи](../FEEDBACK.md). Ничего не публикуется автоматически.

## 2. Выбор редакции

Включите ТВ и подключите его и компьютер или телефон к одной домашней сети. При запросе разрешите CYTV доступ к локальной сети.

- **No-root** — если root-доступа нет. Подготовьте Developer Mode по шагам ниже.
- **Root** — если root-доступ по SSH уже есть. Установщик не получает root. Не включайте Developer Mode на таком ТВ; сохраните доступ по SSH и данные восстановления.

**No-root → Root:** Если после полного удаления снова установлен No-root, перед переходом на Root может потребоваться очистка. Сохраните настройки Home, выберите **Удалить Clean Your TV** с сохранённым Root-подключением и дождитесь подтверждённого удаления. Это удалит и No-root Home с Helper. Затем установите Root; данные восстановления сохраните.

### Настройка Developer Mode (No-root)

Developer Mode позволяет CYTV установить приложения на телевизор без root.

1. На телевизоре откройте LG Apps, найдите Developer Mode и установите это приложение.
2. Откройте Developer Mode и войдите в аккаунт LG Developer. Если аккаунта нет, создайте его на [LG Developer](https://webostv.developer.lge.com).
3. Включите Dev Mode Status. Телевизор перезагрузится. После этого снова откройте Developer Mode.
4. Включите Key Server и оставьте Developer Mode открытым. В поле IP Address указан адрес телевизора для ввода в CYTV.
5. Введите Passphrase — код из шести символов на экране Developer Mode на телевизоре. Соблюдайте регистр букв.

Нужен код с экрана ТВ, а не пароль аккаунта LG. Если кода нет, включите Key Server.

Сопряжение — отдельный шаг: когда телевизор покажет запрос, разрешите подключение CYTV с пульта.

Следите за таймером Developer Mode: до его окончания откройте приложение и нажмите EXTEND при подключённом интернете. Если время истечёт, LG может удалить эти приложения.

## 3. Откройте установщик

- **Windows x64:** скачайте `cytv-windows-x64-desktop.zip`, выберите **Извлечь всё** в Проводнике и откройте `cytv-desktop/cytv-desktop.exe`. Сохраните рядом папку `_internal`.
- **macOS 13+:** распакуйте `cytv-macos-arm64.zip` для Apple Silicon либо `cytv-macos-x64.zip` для Intel. Перенесите `cytv.app` в «Программы» и откройте; разрешите доступ к локальной сети. Если доверенная загрузка заблокирована, используйте «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper.
- **Linux x64:** в Ubuntu 22.04+, Debian 12+ или Mint 21+ установите `cytv-linux-x64.deb` через графический менеджер пакетов, затем откройте Clean Your TV в меню приложений. Для загрузки библиотек может потребоваться интернет. Пакета Linux ARM нет.

**Android ARM64:** нужен 64-битный ARM-телефон с Android 7+ и WebView/Chrome 108+. Откройте скачанный APK и разрешите установку из этого источника, если Android попросит. Запустите CYTV; язык выбирается справа вверху. Обновляйте приложение без удаления и очистки данных.

Оконный мастер сначала выбирает язык системы и сохраняет явно выбранный язык. На телевизоре откройте **Настройки → Язык** и выберите язык либо автоматический вариант, следующий языку телевизора. Настройки языка установщика и телевизора независимы. Все коды приведены в [списке языков](../LANGUAGES.md).

## 4. Установите на телевизор

1. В CYTV выберите **Настроить ТВ**. На компьютере выберите найденный телевизор; на Android введите его IP-адрес. Если поиск не нашёл ТВ, введите адрес вручную.
2. Выберите **No-root** или **Root** и проверьте телевизор перед продолжением.
3. Для No-root введите код с экрана Developer Mode и подтвердите запрос на ТВ. Для Root используйте свои данные SSH; подтверждайте новую SSH-идентичность только для своего ТВ в доверенной сети. Если сохранённый ключ изменился, остановитесь и выясните причину.
4. Следуйте подсказкам мастера. Оставьте ТВ включённым, не меняйте сеть и не закрывайте CYTV до завершения. На Android не останавливайте приложение принудительно. Root включает управление Home сразу после подготовки восстановления.

В следующем, ещё не опубликованном кандидате установка Root продолжится с предупреждением, если входы ТВ недоступны для чтения, но список приложений корректен. Входы могут отсутствовать в Home; ошибка чтения или пустой список приложений по-прежнему останавливают установку. Если предупреждение повторяется, сохраните диагностический отчёт.

## 5. Проверьте кнопки пульта

1. Откройте другое приложение на ТВ и коротко нажмите **Home**. Должен открыться Clean Your TV. Укажите в мастере то, что увидели; если проверку не выполняли, оставьте её пропущенной.
2. Проверьте стрелки, OK, Назад, громкость и звук. Отдельно проверьте выход из ожидания и запуск после полного отключения питания. Успешная установка сама по себе не проверяет эти действия.

<a id="управление-и-восстановление"></a>

## 6. Управление и восстановление

Стрелки выбирают плитку, OK открывает её; удержание OK позволяет менять порядок. Короткое «Назад» сохраняет навигацию и диалог выхода приложения. Короткое Home открывает наш экран, пока управление Home активно. Удержание «Назад» в течение 1,2 секунды однократно открывает LG Home. Переключатель управления Home и ваши настройки не меняются.

**Трижды коротко нажмите Home за две секунды**, отпуская кнопку между нажатиями. Это возвращает LG Home и останавливает управление без сброса настроек.

No-root: Для возобновления откройте Home Helper, выберите «Запустить Helper» и подтвердите. Сохранённый выбор главного экрана не изменится. Root: для возобновления включите **Заменить Home** в настройках Home. **Открыть LG Home** однократно открывает LG Home, не меняя назначение кнопки Home. Чтобы постоянно использовать LG Home, выключите **Заменить Home**. Не запускайте оба обработчика одновременно. При повторном сбое оставьте LG Home активным.

## Нужна помощь?

Если после сброса или изменения SSH появляется `ssh-identity-changed`, остановитесь: CYTV заблокировал изменившийся сохранённый ключ до входа. Первичное подтверждение доверия не заменяет ключ; ожидающее удаление не объясняет несовпадение. Сохраните исходный профиль, ключи и записи восстановления. Поддерживаемой автоматической команды повторного доверия нет. Нужны независимая проверка идентичности/отпечатка TV и проверенная процедура с сохранением профиля: [восстановление при изменении SSH-идентичности](../RECOVERY.md#ssh-identity-changed).

Если установка прервалась, используйте то же сохранённое подключение и сначала выберите **Проверить состояние ТВ**. Продолжайте только по предложенному мастером действию восстановления. При неизвестном состоянии сохраните диагностический отчёт и остановитесь; не удаляйте данные восстановления и не повторяйте установку вслепую.

На время восстановления оставьте управление Home выключенным, сохраните исходные диагностические отчёты и подключение. Проверку и изменения подтверждайте отдельно. Следуйте подробной инструкции восстановления для установленной версии; не переустанавливайте принудительно и не очищайте состояние восстановления.

Для помощи укажите модель ТВ, прошивку, No-root или Root, устройство установки, шаг и текст ошибки. Перед отправкой отчёта удалите пароли, ключи, адреса и другие личные данные. Отчёт не публикуется автоматически.

### Простое удаление (v1.11.0+)

В опубликованной v1.11.0 и новее выберите **Удалить Clean Your TV** в обслуживании с тем же сохранённым подключением к ТВ. Подтвердите один раз. Известные приложения и файлы проекта, которые присутствуют, удаляются; отсутствующие пропускаются, в том числе после частичной установки.

По запросу отключите питание ТВ, подключите снова, дождитесь сети и выберите **Попробовать снова**. Ожидание и Quick Start не являются полным перезапуском; CYTV не перезапускает ТВ автоматически. При потере связи проверьте подключение и повторите ту же цель удаления без другого мастера восстановления. При отказе доступа используйте запрошенное подключение Root; если ТВ занят, подождите и повторите. Успех показывается только после проверки финальной очистки. Сохраните ключи и исходные отчёты. Аварийное управление и согласие на публикацию выше остаются в силе.

Начиная с v1.11.0 после ошибки или прерывания установки сразу доступно восстановление. Если No-root нельзя продолжить, подтвердите полное удаление один раз. При кратковременной потере связи или занятом процессе CYTV удаление повторяет проверку автоматически, всего до трёх попыток. Если нужны права Root, выберите **Подключиться через Root** для того же ТВ; проверенная очистка Root также завершит заблокированное No-root удаление. При сбое активации Root установщик пытается вернуть и проверить LG Home без повторной активации. Отмена незавершённой операции сохраняет отчёт и действия восстановления. Состояние аварийной остановки сохраняется.
