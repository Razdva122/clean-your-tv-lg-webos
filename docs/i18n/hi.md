## संस्करण चुनें

No-root और Root अलग-अलग टीवी सेटअप के लिए समान दर्जे के विकल्प हैं। LG Developer Mode के लिए No-root चुनें या पहले से root SSH पहुँच होने पर Root चुनें। संगतता और किए गए परीक्षणों का दायरा हर संस्करण के लिए अलग है।

- **No-root:** LG Developer Mode और Key Server चालू करें। टीवी पर दिखाया पासफ़्रेज़ भरें और टीवी पर आने वाला अलग पेयरिंग अनुरोध स्वीकार करें। Developer Mode सक्रिय रहना चाहिए; अवधि समाप्त होने पर इस तरीके से लगाए ऐप हट सकते हैं। Beta नवीनीकरण चालू होने पर भी आधिकारिक टाइमर देखें। Helper की निगरानी के लिए स्थानीय नेटवर्क चाहिए।
- **Root:** पहले से काम करता root SSH प्रवेश आवश्यक है। इंस्टॉलर टीवी को root नहीं करता। पहले से root किए टीवी पर Developer Mode चालू न करें। root प्रवेश और पुनर्प्राप्ति सेवाएँ उपलब्ध रखें।

Root के लिए Settings Service और System Profile (`com.webos.service.systemprofile`) के Home इंटरफ़ेस काम करने चाहिए; केवल root पहुँच से अनुकूलता की पुष्टि नहीं होती।

> **1.6.0:** Root निजी Python या पैकेज तैयार करने से पहले आवश्यक Home इंटरफ़ेस जाँचता है। जाँच विफल होने पर सेटअप रुकता है; सफल जाँच फ़र्मवेयर अनुकूलता या वास्तविक Home बटन के काम करने का प्रमाण नहीं है। ज्ञात कनेक्शन त्रुटियों के लिए अलग निर्देश मिलते हैं। प्रोफ़ाइल, भरोसे की जानकारी और पुनर्प्राप्ति डेटा सुरक्षित रखें; अधूरे काम के लिए सत्यापित पुनर्प्राप्ति चाहिए, बिना जाँच दोबारा प्रयास नहीं। निदान रिपोर्ट सहेजें और जाँचें। [विवरण](../development/INSTALLER-PREFLIGHT-HELP.md)।

## स्थापना से पहले

टीवी चालू रखें और कंप्यूटर को उसी भरोसेमंद स्थानीय नेटवर्क से जोड़ें। बाद में कंप्यूटर बंद रह सकता है। अनुकूलता मॉडल, फ़र्मवेयर और रिमोट पर निर्भर है। Root के लिए वास्तविक उपकरण पर कुछ जाँच बाकी हैं।

1.5.4 में TV Node.js **0.10.25+** समर्थित Home Helper **0.6.21** शामिल है; Root के लिए अभी भी Node.js **8+** चाहिए। [Compatibility](../COMPATIBILITY.md).

No-root Helper को टीवी पर Node.js **0.10.25+** चाहिए। Root को Node.js **8+** और काम करता Python **3.9+** चाहिए। आवश्यकता होने पर इंस्टॉलर सत्यापित निजी Python डाउनलोड करता है; शुरुआती तैयारी के लिए **320 MiB** खाली जगह चाहिए। यह सिस्टम Python नहीं बदलता। पुनर्प्राप्ति के काम आने वाले रनटाइम सुरक्षित रखें। [Python (अंग्रेज़ी)](../OPTIONAL-PYTHON.md)। Developer Mode स्वतः नवीनीकरण **Beta है और डिफ़ॉल्ट रूप से बंद है**। बिना root टीवी पर वास्तविक नवीनीकरण की पुष्टि नहीं हुई है; आधिकारिक टाइमर देखते रहें।

### Developer Mode सेटअप (No-root)

Developer Mode से CYTV बिना root वाले TV पर ऐप इंस्टॉल कर सकता है।

1. TV पर LG Apps खोलें, Developer Mode खोजें और इंस्टॉल करें।
2. Developer Mode खोलें और अपने LG Developer खाते से साइन इन करें। ज़रूरत हो तो webostv.developer.lge.com पर खाता बनाएँ।
3. Dev Mode Status चालू करें। TV फिर से शुरू होगा। उसके बाद Developer Mode दोबारा खोलें।
4. Key Server चालू करें और Developer Mode खुला रखें। वहाँ दिखा IP Address ही CYTV में डालने वाला TV का पता है।
5. TV के Developer Mode में दिखे छह अक्षरों वाला Passphrase डालें। बड़े और छोटे अक्षर जैसे दिखें वैसे ही लिखें।

LG खाते का पासवर्ड नहीं, TV पर दिखा कोड डालें। कोड न दिखे तो Key Server चालू करें।

पेयरिंग अलग चरण है: TV पर अनुरोध आने पर रिमोट से CYTV को अनुमति दें।

Developer Mode चालू रखें: समय खत्म होने से पहले इसे खोलें और TV के इंटरनेट से जुड़े होने पर EXTEND दबाएँ। समय खत्म होने पर LG ये ऐप हटा सकता है।

## स्थापना और भाषा

- **Windows x64:** `cytv-windows-x64-desktop.zip` डाउनलोड करें, फ़ाइल एक्सप्लोरर में **Extract All** चुनें, फिर `cytv-desktop/cytv-desktop.exe` खोलें। `_internal` फ़ोल्डर उसके साथ रखें। Windows प्रकाशक हस्ताक्षर कॉन्फ़िगर नहीं है। अलग कंसोल `cytv-windows-x64.exe` है; नीचे के PowerShell आदेशों के लिए इसका नाम `cytv.exe` रखें और `.\cytv.exe` चलाएँ।
- **macOS 13 या नया:** Apple Silicon के लिए `cytv-macos-arm64.zip`, Intel के लिए `cytv-macos-x64.zip` खोलें। `cytv.app` को Applications में रखें और खोलें। स्थानीय नेटवर्क की अनुमति दें। भरोसेमंद डाउनलोड रुकने पर Privacy & Security → Open Anyway चुनें; Gatekeeper बंद न करें। पुराने सिस्टम की जाँच पूरी नहीं हुई है।
- **Linux x64:** Ubuntu 22.04+, Debian 12+ या Mint 21+ पर `cytv-linux-x64.deb` को ग्राफ़िकल पैकेज प्रबंधक से स्थापित करें और ऐप मेनू से Clean Your TV खोलें। लाइब्रेरी के लिए इंटरनेट लग सकता है। Linux ARM पैकेज नहीं है। अलग `cytv-linux-x64` निष्पादन फ़ाइल CLI है; ग्राफ़िकल ऐप के लिए `.deb` लें।

[Android इंस्टॉलर (अंग्रेज़ी)](../../android/README.md): ऊपर दाईं ओर भाषा चुनें। ऐप हटाए या डेटा मिटाए बिना अपडेट करें। Android 7 / WebView 108 न्यूनतम आवश्यकता है, सत्यापित फ़ोन नहीं; स्वीकृति Android 15 ARM64 / WebView 124 एमुलेटर पर हुई। वास्तविक फ़ोन और वास्तविक टीवी से जुड़ी पुनर्प्राप्ति सत्यापित नहीं हैं।

डेस्कटॉप सहायक शुरू में सिस्टम की भाषा चुनता है और आपकी चुनी भाषा सहेजता है। टीवी पर **सेटिंग्स → भाषा** में भाषा चुनें या टीवी की भाषा अपनाने वाला स्वचालित विकल्प चुनें। इंस्टॉलर और टीवी की भाषा सेटिंग अलग हैं। कोड [भाषा सूची](../LANGUAGES.md) में हैं।

macOS/Linux पर अलग से डाउनलोड की CLI के लिए, निकाली गई फ़ाइलों के फ़ोल्डर में:

```sh
chmod +x cytv
./cytv --language hi install
```

टीवी चुनें या उसका IP भरें, संस्करण चुनें और सारांश जाँचें। नई SSH पहचान केवल भरोसेमंद नेटवर्क पर अपने टीवी के लिए स्वीकार करें; सहेजी गई कुंजी बदलने पर प्रवेश रुकता है। Root पुनर्प्राप्ति तैयार करके Home तुरंत चालू करता है; परीक्षण अवधि या बनाए रखने की पुष्टि नहीं है। दिशा बटन, OK, Home, वापस/रद्द, आवाज़, स्टैंडबाय से वापसी और पूरी बिजली बंद करके दोबारा चालू करने की जाँच करें।

**1.6.0:** पैकेज सत्यापन, प्रारंभ जाँच और भौतिक Home का आपका अवलोकन अलग दिखते हैं। प्रारंभ की पुष्टि या Helper प्रक्रिया Home इंटरसेप्शन का प्रमाण नहीं है। दूसरा टीवी ऐप खोलें, Home एक बार संक्षेप में दबाएँ और परिणाम चुनें; डिफ़ॉल्ट **जाँचा नहीं / छोड़ें** है। `--yes` आपकी ओर से उत्तर नहीं देता; गैर-संवादात्मक स्थापना इसे अनजाँचा छोड़ती है। Home की विफलता या छोड़ी जाँच पैकेज नहीं हटाती और पुनर्स्थापना शुरू नहीं करती। सहायता के लिए स्थानीय रिपोर्ट सहेजें; यह अपने आप प्रकाशित नहीं होती। अन्य बटन, ध्वनि, स्टैंडबाय और पूर्ण बूट अलग जाँचें हैं।

## उपयोग और पुनर्प्राप्ति

दिशा बटन से चुनें, OK से खोलें; क्रम बदलने के लिए OK दबाए रखें। वापस का छोटा दबाव ऐप का नेविगेशन और बाहर निकलने की पुष्टि बनाए रखता है। Home नियंत्रण चालू हो तो छोटा Home लॉन्चर खोलता है। वापस बटन 1.2 सेकंड दबाए रखने से LG Home एक बार खुलता है। Home नियंत्रण का स्विच और आपकी सेटिंग्स नहीं बदलते।

**दो सेकंड में Home तीन बार दबाएँ**, हर बार बटन छोड़ें। इससे पसंद मिटाए बिना LG Home लौटता है और नियंत्रण रुकता है। पुराने No-root Helper 0.6.13 तक इसके बजाय Home लगभग दो सेकंड दबाए रखें। Home दबाए रखना Root की आपातकालीन क्रिया नहीं है।

No-root: Home नियंत्रण फिर शुरू करने के लिए Home Helper खोलें, Helper शुरू करें चुनें और पुष्टि करें। चुनी हुई Home स्क्रीन बनी रहती है। Root: फिर शुरू करने के लिए Home सेटिंग्स में **Home बदलें** चालू करें। **LG Home खोलें** से Home का गंतव्य बदले बिना LG Home एक बार खुलता है। LG Home को स्थायी गंतव्य बनाने के लिए **Home बदलें** बंद करें या `cytv restore` चलाएँ। दोनों नियंत्रक एक साथ न चलाएँ। समस्या दोबारा हो तो LG Home चालू रहने दें।

> **1.5.4 — Root:** Root ठीक होने पर **Home बदलें** को स्पष्ट रूप से चालू करने से CYTV का अपना मूल TV इनपुट **Clean** बनता है और याद रखा गया इनपुट Clean पर सेट होता है। Home नियंत्रण बंद करने, आपात रोक, त्रुटि, अपडेट के लिए निलंबन या हटाने पर CYTV अपनी प्रविष्टि हटाता है। पिछला इनपुट तभी बहाल होता है जब वर्तमान मान अभी भी CYTV का सेट किया हुआ हो; दूसरे इनपुट और सामने खुले ऐप सुरक्षित रहते हैं। असमर्थित TV या CYTV के स्वामित्व से बाहर की प्रविष्टि पर सामान्य सुरक्षित Home नियंत्रण बना रहता है। Clean तुरंत पहली स्क्रीन होगा, इसकी गारंटी नहीं है। दर्ज C3 पहली स्क्रीन, स्टैंडबाय और बिजली काटकर शुरू करने की जाँच सफल रही; सभी उपकरणों की गारंटी नहीं है। अपडेट/रोलबैक के बाद Home बंद रह सकता है (#202), और सेटिंग्स पुरानी स्थिति दिखा सकती हैं (#206): सेटिंग्स बंद करके फिर खोलें, Home बदलें स्पष्ट रूप से चालू करें और Clean स्थिति की प्रतीक्षा करें। [1.5.4 QA (English)](../history/2026-10-31-release-1.5.3-signed-root-qa.md) · [Native input (English)](../development/ROOT-NATIVE-INPUT.md).

> **1.6.0 (#152):** Helper बंद करने का अनुरोध अस्वीकार होने पर No-root पुनर्स्थापन/हटाने की प्रक्रिया सत्यापित SSH रोक का उपयोग कर सकेगी। रोक की स्थिति बनी रहती है; परिणाम अनिश्चित होने पर जर्नल सुरक्षित रहता है। स्थिति फ़ाइलें न मिटाएँ। EF950V पर पुष्टि अभी बाकी है। [#152](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/152)

> **1.6.0 (#201):** No-root स्थिति बाधित इंस्टॉलेशन या हटाने का जर्नल सुरक्षित रखती है। मेल खाती फ़ाइलें या ऐप का न होना प्रक्रिया पूरी होने का प्रमाण नहीं है। जाँच अस्वीकार होने पर रुकें और निदान सुरक्षित रखें; केवल फ़ाइलों के आधार पर जाँच को छोड़ने का तरीका उपलब्ध नहीं है। [#201](../RECOVERY.md#unreleased-uncertain-no-root-package-operations-201)

रुकावट के बाद दोबारा प्रयास से पहले `status` चलाएँ और लॉग रखें। `restore` ऐप हटाए बिना LG Home लौटाता है; `uninstall` हटाने से पहले बहाल करता है। Root पुनर्प्राप्ति डेटा जानबूझकर रखा जाता है; दोबारा स्थापना मजबूर करने के लिए उसे न मिटाएँ। रिपोर्ट साझा करने से पहले देखें; कुंजियाँ या प्रोफ़ाइल फ़ोल्डर प्रकाशित न करें।

**Home सेटिंग्स → दिखावट → कॉलम** खोलकर 1–8 कॉलम चुनें, या थीम का मान इस्तेमाल करने के लिए **थीम के अनुसार** चुनें (Classic का डिफ़ॉल्ट: 5)। चुनी हुई संख्या को थीम पर प्राथमिकता मिलती है। निश्चित लेआउट वाली थीम में कॉलम विकल्प छिपा रहता है और लेखक का मान लागू होता है। इस सेटिंग का समर्थन करने वाली थीम पर लौटने पर आपका सहेजा हुआ विकल्प फिर लागू होगा। डाउनलोड की गई Alpine थीम में ऐप एक ही चक्रीय क्षैतिज पंक्ति में हैं: बायाँ/दायाँ स्क्रॉल करता है, ऊपर शॉर्टकट खोलता है और नीचे उसी ऐप पर लौटता है। Alpine में माउस व्हील या टचपैड से भी पंक्ति स्क्रॉल कर सकते हैं; खुले संवाद के पीछे Home नहीं चलता।

1.5.4: **Home सेटिंग्स → दिखावट** में **ऐप जोड़ें टाइल दिखाएँ** बंद करके + टाइल छिपाएँ। यह डिफ़ॉल्ट रूप से चालू है। + छिपा होने पर भी इसी भाग में **ऐप जोड़ें** से ऐप जोड़ या वापस ला सकते हैं। ऐप का क्रम बदलना और छिपाना उपलब्ध रहता है; चुनाव रीस्टार्ट के बाद भी बना रहता है। सभी ऐप छिपाने पर भी ऊपर के बटन और सेटिंग्स उपलब्ध रहते हैं।

अप्रकाशित: चुनी हुई थीम तय करती है कि **इनपुट** ऊपर के मेनू में हों या HDMI शेल्फ़ में; स्थान का कोई वैश्विक विकल्प या **Home पर इनपुट दिखाएँ** स्विच नहीं है। शेल्फ़ अभी केवल `dock-grid` में समर्थित है। Liquid Glass इसे चुनती है; Classic और इस विकल्प के बिना थीम ऊपर का मेनू रखती हैं। डॉक से ऊपर दबाने पर शेल्फ़, फिर ऊपर से शीर्ष बटन आते हैं; नीचे या वापस से डॉक पर लौटें और OK से स्रोत खोलें। स्रोत की टाइलें होने पर शेल्फ़ ऊपर के इनपुट मेनू की जगह लेती है। डिवाइस का नाम EIM मेटाडेटा से तभी मिलता है जब फ़र्मवेयर उसे दे; नहीं तो जुड़े स्रोत पर **कनेक्ट है** दिखता है। Home PlayStation का नाम नहीं गढ़ता और CEC पहचान की गारंटी नहीं देता। खाली पोर्ट भी चुने जा सकते हैं। पूर्वावलोकन **डिफ़ॉल्ट रूप से चालू** हैं; स्पष्ट रूप से सहेजा गया बंद विकल्प बंद ही रहता है। इन्हें बंद करने के लिए **Home सेटिंग्स → दिखावट → चुने गए इनपुट का पूर्वावलोकन** बंद करें। चालू होने और चुनी थीम में शेल्फ़ होने पर जुड़े HDMI पर लगभग 0.8 सेकंड रुककर पूर्वावलोकन दिख सकता है। कुछ TV पर HDMI पूर्वावलोकन आवाज़ चला सकते हैं या HDR चालू कर सकते हैं; चुप रहने की गारंटी नहीं है। Home TV की वैश्विक म्यूट या HDR सेटिंग अपने आप नहीं बदलता। Live TV और खाली पोर्ट स्थिर टाइल रखते हैं।

1.5.4 की वैकल्पिक साइडबार वाली थीम के प्रीव्यू में ऊपर/नीचे से मेनू का विकल्प चुनें, दाएँ से ऐप्स पर जाएँ और ऐप्स के पहले कॉलम से बाएँ दबाकर मेनू पर लौटें।

No-root 1.5.0: स्टैंडबाय से जागने पर अस्थायी watchdog टाइमआउट के बाद Helper दस मिनट में अधिकतम पाँच बार पुनः शुरू हो सकता है। Stop और तीन बार Home दबाने के बाद Helper को स्पष्ट रूप से शुरू करना अभी भी ज़रूरी है; बार-बार विफल होने पर वह बंद रहता है। TV पर सत्यापन बाकी है। [व्यवहार और सीमाएँ (अंग्रेज़ी)](../HELPER-DIAGNOSTICS.md#watchdog-recovery-unpublished-candidate-155).

## अपडेट और हटाना

कनेक्ट होने पर cytv स्थापित → शामिल संस्करण दिखाता है और पहली स्थापना, पुनः स्थापना तथा पुराने संस्करण पर जाने में अंतर बताता है। पुष्टि से पहले सारांश पढ़ें; `--yes` संगतता जाँच नहीं हटाता। काम करने वाले पैकेज और सेटिंग्स की निजी प्रतियाँ रखें। कंप्यूटर से पैकेज बदलने से पहले No-root Helper रोकें; पहले अनइंस्टॉल न करें। चालू Root पर केवल एक IPK न चढ़ाएँ: cytv की तय प्रक्रिया अपनाएँ। कंप्यूटर ऐप हटाने से टीवी ऐप नहीं हटते।

Home सेटिंग्स → सॉफ़्टवेयर अपडेट खोलें और पुष्टि से पहले संस्करण जाँचें। टीवी पर अपडेट और रोलबैक के लिए No-root संस्करण में भी **root, Homebrew Channel** और पहले से तैयार संगत अपडेट ढाँचा चाहिए। बिना root कंप्यूटर उपयोग करें। पूरे सिस्टम के अपडेट की तैयारी अलग स्पष्ट कार्रवाई है: [अपडेट (अंग्रेज़ी)](../UPDATES.md)। पुनर्प्राप्ति में सहेजा रोलबैक संस्करण देखें; बाद में किए सेटिंग्स बदलाव खो सकते हैं।

**पहले से स्थापित 1.3.0:** उसका मूल System Updater बदली हुई संरचना को अस्वीकार कर सकता है। अधूरा काम सुरक्षित रखें और 1.5.0+ के लिए दर्ज जाँची हुई पुनर्प्राप्ति व बदलाव की तैयारी अपनाएँ; रिकॉर्ड न मिटाएँ और बिना जाँच दोबारा न चलाएँ। केवल ऐप अपडेट करने से सुरक्षित Root संरचना नहीं बदलती। [स्थानांतरण और पुनर्प्राप्ति (अंग्रेज़ी)](../UPDATES.md#one-time-computer-preparation)।

Home सेटिंग्स चैनल का सुधार 1.5.0 में प्रकाशित हुआ है। संगत प्रकाशित इंस्टॉलर से Home और Helper को साथ अपडेट करें; केवल Home अपडेट करने से Helper नहीं बदलता। सत्यापन दर्ज किए गए मॉडलों तक सीमित है। [#146](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/146).

Root HDMI आवाज़ पुनर्प्राप्ति प्रयोगात्मक है और **डिफ़ॉल्ट रूप से बंद है**; जरूरत होने पर ही चालू करें। यह ठीक चल रही आवाज़ रोक सकती है और eARC संगतता सिद्ध नहीं करती। [आवाज़ पुनर्प्राप्ति (अंग्रेज़ी)](../development/ROOT-AUDIO-RECOVERY.md)। अलग **Homebrew CYTV Installer अभी जारी नहीं हुआ है**; प्रकाशित कंप्यूटर या Android इंस्टॉलर उपयोग करें।

Homebrew Channel ने इस इंस्टॉलर की पहुँच रोक दी। webOS 11 पर Homebrew 0.7.3 को उसके डेवलपर से संगतता अपडेट चाहिए। सुधार वाला समर्थित Homebrew संस्करण आने तक प्रकाशित कंप्यूटर या Android इंस्टॉलर उपयोग करें। [#116](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/116).

1.5.0+: यदि पुराने Root फ़ोल्डरों की लिखने की अनुमति से फ़र्मवेयर API पहुँच रुकती है, तो `cytv enable-firmware-access --edition root --repair-package-permissions` वर्तमान पैकेज को विश्वसनीय निजी रिकॉर्ड से जाँचकर केवल Root के अपने पथों से समूह/अन्य की लिखने की अनुमति हटाता है। अज्ञात या बदली फ़ाइल पर मरम्मत रुकती है। प्रोफ़ाइल, Home चयन और फ़र्मवेयर अवरोध सेटिंग सुरक्षित रहते हैं। [विवरण (अंग्रेज़ी)](../LG-FIRMWARE-UPDATES.md#explicit-package-permission-repair-candidate).

1.5.0+: `cytv recover-system-rollback --edition root` उस जाँचे गए Root रोलबैक के लिए है जिसमें सभी पैकेज इंस्टॉलर पूरे हुए, लेकिन लॉन्चर की तैयारी की समयसीमा समाप्त हो गई। असली लॉन्चर का तैयारी संकेत जरूरी है; अज्ञात स्थापना परिणाम स्वीकार नहीं होते। पैकेज, तय कोड/कुंजियाँ, विफलता के प्रमाण और स्पष्ट रूप से बंद किया गया Home नियंत्रण सुरक्षित रहते हैं। सीमित प्रयास का निजी रिकॉर्ड रखा जाता है। सामान्य पुनः प्रयास समयसीमा नहीं बढ़ाता। पिछले 120 सेकंड समाप्त होने के बाद ही, बिना स्वीकृत तैयारी संकेत या अज्ञात स्थापना परिणाम के, `--new-recovery-attempt` पूरा पिछला रिकॉर्ड उसके UUID/हैश के साथ सुरक्षित कर नया प्रयास शुरू करता है। पूरी हो चुकी पुनर्प्राप्ति फिर नहीं चलती; प्रयास अपने आप दोहराए नहीं जाते। [प्रक्रिया और सीमाएँ (अंग्रेज़ी)](../RECOVERY.md#root-system-rollback-readiness-candidate)।

1.6.0: System Updater 1.2.0 अनुमत नए सेटअप या `cytv replace-system-updater --edition root` से सत्यापित 1.1.0/1.1.1 प्रतिस्थापन के लिए है। केवल System Updater बदलता है; Root/Root Updater ऐप, पूरा प्रोफ़ाइल और Home चयन सुरक्षित रहते हैं तथा पुरानी स्थिति संग्रहित होती है। अज्ञात या अधूरे कार्य प्रतिस्थापन रोकते हैं। पहले से स्थापित 1.1.2 अपने पुराने चैनलों पर पिन रहता है; सामान्य माइग्रेशन उपलब्ध नहीं है। जबरन प्रतिस्थापन न करें। यह शर्त No-root फ़ीड को नहीं रोकती। [प्रक्रिया (अंग्रेज़ी)](../RECOVERY.md#replace-the-root-system-updater-candidate)

## थीम

अगले संस्करण के पूर्वावलोकन में **Home सेटिंग → वॉलपेपर** सक्रिय थीम का वॉलपेपर, टीवी की पहचानी गई क्षमता और वर्तमान मोड दिखाता है। ऑटो संगत गुणवत्ता चुनता है; 4K, 1080p और चित्र तभी उपलब्ध हैं जब थीम में शामिल हों। वीडियो विफल होने पर चित्र दिखता है। अंधेरापन 5% के चरणों में बदलें या थीम के डिफ़ॉल्ट बहाल करें। Classic और बिना वॉलपेपर वाली थीम की स्थिति स्पष्ट दिखाई जाती है।

अगले संस्करण के पूर्वावलोकन में निजी वॉलपेपर: डेस्कटॉप CYTV में Wallpapers खोलें, JPG/PNG चुनें, क्रॉप समायोजित करें और Home की सेटिंग में दिखा टीवी का निजी पता तथा रिसीविंग PIN दर्ज करें। CYTV बिना आवाज़ वाला वीडियो स्थानीय रूप से बनाता है; क्रॉप का रिज़ॉल्यूशन पर्याप्त होने पर ही 4K मिलता है। टीवी पर CYTV से प्राप्त करना या फ़ोन से अपलोड चुनें और उसी Wi-Fi पर QR स्कैन करें। फ़ोन सामान्य चित्र अधिकतम 1920×1080 भेजता है, नेटिव 4K वीडियो लेयर नहीं; स्पष्टता टीवी इंटरफ़ेस के रिज़ॉल्यूशन तक सीमित है। भेजने से पहले चेतावनी स्वीकार करें, फिर टीवी पर पूर्वावलोकन देखकर लागू करें। थीम बदलने पर निजी वॉलपेपर बना रहता है; Wallpapers में थीम का चित्र वापस चुनें या निजी चित्र हटाएँ। रद्द करने या फ़ाइल अस्वीकार होने पर पुराना बैकग्राउंड सुरक्षित रहता है। अगले संस्करण के संगत Home/सेवा और CYTV बिल्ड चाहिए।

Android CYTV: **टीवी सेट करें** · **वॉलपेपर** · **रखरखाव**. टीवी पर Home सेटिंग → वॉलपेपर → फ़ोन से अपलोड खोलें। फ़ोन कैमरे से QR स्कैन करें, JPG/PNG चुनें और टीवी पर लागू करें। फ़ोन से: 1920×1080 तक की तस्वीरें, नेटिव 4K वीडियो नहीं। असली 4K के लिए कंप्यूटर पर CYTV इस्तेमाल करें।

1.7.0 कैंडिडेट: **सेटिंग → थीम** खोलें। **Classic**, **Liquid Glass**, **Ribbon** अंतर्निहित हैं; थीम डाउनलोड नहीं चाहिए और प्रारंभिक चयन Classic है। **Channel** showcase की बाहरी थीम है।गैलरी परीक्षण में:  चुनने के बाद **20 सेकंड** में **थीम रखें** दबाएँ। **पहले जैसा करें**, Back या समय समाप्त होने पर पिछली थीम लौटती है। पुष्टि से पहले Home बंद हो जाए तो अगली शुरुआत में Classic लौटता है। स्थापित सूची से चुनी गई अंतर्निहित और डाउनलोड की गई थीम बिना पुष्टि टाइमर तुरंत लागू और सहेजी जाती हैं। कंप्यूटर से प्राप्त या URL से स्थापित थीम पर भी यही लागू है। केवल गैलरी में थीम आज़माएँ से 20 सेकंड का परीक्षण शुरू होता है।

1.7.0: **Classic**, **Liquid Glass** और **Ribbon** अंतर्निहित हैं। **Alpine 1.4.4** अब **थीम गैलरी** से डाउनलोड की जाती है। सहेजा हुआ `builtin:alpine` चयन मौजूदा दिखाई देने वाली रिकवरी सूचना के साथ Classic पर लौटता है; Home न Alpine अपने आप डाउनलोड करता है, न उसे Liquid Glass से बदलता है। प्रकाशित 1.6.0 में Classic, Alpine और Ribbon शामिल हैं।

इंस्टॉल की गई थीम क्षैतिज रूप से स्क्रॉल होने वाली एक पंक्ति में दिखती हैं। सक्रिय थीम हमेशा पहले होती है और उसका कार्ड हाइलाइट होता है। पंक्ति में जाने के लिए बाएँ/दाएँ बटन दबाएँ।

गैलरी में केवल इस टीवी पर इंस्टॉल नहीं की गई थीम दिखती हैं। Classic, Liquid Glass, Ribbon और डाउनलोड की गई थीम नया संस्करण होने पर भी छिपी रहती हैं। हटाने के बाद थीम फिर दिखती है। अपडेट URL या कंप्यूटर से प्राप्त करें।

थीम कार्ड सेटिंग श्रेणियों के साथ थीम में ही दिखते हैं। गैलरी, लिंक से इंस्टॉल और कंप्यूटर ट्रांसफ़र उसी पैनल में खुलते हैं; केवल गैलरी परीक्षण में Home थोड़ी देर दिखता है।

गैलरी खोलने या रीफ़्रेश चुनने पर Home अपडेट या पेज दोबारा लोड किए बिना मुख्य प्रोजेक्ट रिपॉज़िटरी से समीक्षित कैटलॉग अपडेट जाँचे जाते हैं। सामान्य मर्ज के बाद नई प्रविष्टियाँ मिलती हैं; बिना मर्ज वाला कैंडिडेट शामिल कैटलॉग दिखा सकता है। ऑफलाइन या त्रुटि पर शामिल प्रविष्टियाँ और पूर्वावलोकन उपयोग होते हैं। अंतर्निहित थीम स्थापित Home संस्करण से मेल खाती हैं। Channel का पूर्वावलोकन खोलें और **थीम डाउनलोड करें** चुनें (इंटरनेट आवश्यक)। डाउनलोड के बाद आज़माएँ और **20 सेकंड** में थीम रखें चुनें। स्थापित थीम ऑफलाइन चलती हैं। निश्चित लिंक के लिए URL से जोड़ना भी उपलब्ध है।

अप्रकाशित थीम जाँचने के लिए पहले टीवी पर **सेटिंग्स → थीम → कंप्यूटर से प्राप्त करें** खोलें। वहाँ दिखा टीवी पता और छह अंकों का PIN कंप्यूटर पूर्वावलोकन के **Send to TV** में दर्ज करें, भेजें और टीवी पर **थीम लागू करें** चुनें। मुख्य तरीका पीसी से टीवी के TCP **8879** पर जाता है; कंप्यूटर फ़ायरवॉल बदलना नहीं पड़ता। दोनों डिवाइस एक ही विश्वसनीय घरेलू नेटवर्क पर हों। एक अपलोड, रद्द करने, स्क्रीन छोड़ने या **10 मिनट** बाद रिसीवर बंद होता है। PIN सहेजा नहीं जाता और स्थापित थीम ऑफलाइन चलती है। GitHub प्रकाशन आवश्यक नहीं है।

प्रकाशित थीम के लिए **ID से जोड़ें** खोलें और ID (जैसे `102300a209`), `da.gd/102300a209` या पूरा GitHub लिंक दर्ज करें। Home लोड करने से पहले da.gd पता दिखाता है और GitHub गंतव्य व थीम पैकेज की जाँच करता है। लेखक रिलीज़ नोट्स या कंप्यूटर पूर्वावलोकन में **TV link → Copy ID** से ID दे सकता है।

## सेटिंग श्रेणियाँ (1.5.4)

दोनों संस्करणों में बाईं ओर श्रेणियाँ और दाईं ओर चुनी गई सेटिंग दिखाई देती हैं: होम स्क्रीन, दिखावट, थीम, भाषा, सॉफ़्टवेयर अपडेट और उन्नत। No-root में Developer Mode भी है। Root में LG फ़र्मवेयर अपडेट, अपडेट श्रेणी में और HDMI ध्वनि, उन्नत में है। ऊपर/नीचे से कॉलम में चलें, दाएँ से सेटिंग में जाएँ और बाएँ से श्रेणियों पर लौटें। वापस पहले श्रेणियों पर लौटता है, फिर सेटिंग बंद करता है। Tab से Home पर लौटने वाला बटन भी चुन सकते हैं।

सॉफ़्टवेयर अपडेट श्रेणी और उसके अंदर के बटन पर पीला बिंदु उपलब्ध अपडेट दिखाता है। सफल जाँच में अपडेट न मिलने पर दोनों हट जाते हैं; जाँच विफल होने पर पिछली पुष्टि की गई स्थिति बनी रहती है।

## स्वचालित ग्राफ़िक्स रिज़ॉल्यूशन (1.6.0)

1.6.0 के कंप्यूटर/Android इंस्टॉलर और माइग्रेट किए गए OTA क्लाइंट टीवी की बताई क्षमता के अनुसार 720p या 1080p चुनते हैं। पुष्टि न होने पर प्रक्रिया रुक जाती है। अलग से स्थापित पुराने अपडेटर के लिए दस्तावेज़ में बताया कंप्यूटर माइग्रेशन आवश्यक है; रिकवरी मूल पैकेज सुरक्षित रखती है।

[HD/FHD details (English)](../development/HOME-GRAPHICS-RESOLUTION.md#automatic-selection-and-ota).

> **1.6.0:** मूल विफल प्रयास की रिपोर्ट सुरक्षित रखें। नई रिपोर्ट में दर्ज पहली त्रुटि बाद की जाँचों से अलग होती है और Doctor/स्थिति का फ़िल्टर किया गया सारांश मिलता है। सफल स्थापना, स्थिति जाँच और बहाली के बाद भी रिपोर्ट सहेज सकते हैं। पुराने अनुपलब्ध प्रमाण अज्ञात ही रहते हैं; रिपोर्ट पुनर्प्राप्ति की अनुमति नहीं देती। [↗](../development/INSTALLER-DIAGNOSTICS.md).
