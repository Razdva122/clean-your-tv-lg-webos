## 에디션 선택

No-root와 Root는 서로 다른 TV 환경에 맞는 동등한 선택지입니다. LG Developer Mode를 사용하면 No-root를, 기존 root SSH 접근 권한이 있으면 Root를 선택하세요. 호환성과 테스트 범위는 각 버전마다 다릅니다.

- **No-root:** LG Developer Mode와 Key Server를 켜세요. TV에 표시된 암호 문구를 입력하고 별도로 표시되는 페어링 요청을 TV에서 승인하세요. Developer Mode를 계속 활성화해야 합니다. 세션이 만료되면 설치한 앱이 삭제될 수 있습니다. 베타 자동 갱신을 켰더라도 공식 타이머를 확인하세요. Helper의 상태 감시에는 로컬 네트워크가 필요합니다.
- **Root:** 기존 root SSH 접근 권한이 필요합니다. 설치 프로그램은 TV를 루팅하지 않습니다. 이미 루팅한 TV에는 Developer Mode를 켜지 마세요. root 접근 및 복구 서비스를 유지하세요.

Root (System Profile)에는 Settings Service 및 System Profile (`com.webos.service.systemprofile`)의 정상적인 Home 인터페이스가 필요합니다. root 권한만으로 호환성이 보장되지는 않습니다.

> **1.6.0:** Root는 전용 Python이나 패키지를 준비하기 전에 필요한 Home 인터페이스를 확인합니다. 실패하면 설치가 중단됩니다. 통과해도 펌웨어 호환성이나 실제 Home 버튼 동작이 입증되지는 않습니다. 알려진 연결 오류에는 개별 안내가 표시됩니다. 프로필, 신뢰 정보와 복구 데이터를 보존하세요. 미완료 작업은 무작정 재시도하지 말고 검증된 복구가 필요합니다. 진단 보고서를 저장하고 검토하세요. [자세히](../development/INSTALLER-PREFLIGHT-HELP.md).

## 설치 전 준비

TV를 켜고 컴퓨터와 같은 신뢰할 수 있는 로컬 네트워크에 연결하세요. 설치 후에는 컴퓨터를 꺼도 됩니다. 호환성은 모델, 펌웨어, 리모컨에 따라 다릅니다. Root는 실제 기기 검증이 남아 있습니다.

1.5.4에는 TV Node.js **0.10.25+**를 지원하는 Home Helper **0.6.21**이 포함됩니다. Root는 계속 Node.js **8+**가 필요합니다. [Compatibility](../COMPATIBILITY.md).

**webOS 1.x — 1.8.2:** 공개된 No-root 설치 프로그램은 Helper 0.7.4를 포함하며 정확한 런타임 검사 후 TV Node.js **0.10.15+**를 허용합니다. 오래된 WebKit, 네이티브 입력 또는 Home 호환성을 확인한 것은 아닙니다. TV 런타임을 교체하거나 검사를 우회하지 마세요. Root는 여전히 Node.js 8+가 필요합니다. [검사와 제한](../COMPATIBILITY.md#webos-1x-runtime-floor-unreleased).

No-root Helper에는 TV Node.js **0.10.15+**가 필요합니다. Root에는 Node.js **8+**와 정상 작동하는 Python **3.9+**가 필요합니다. 필요하면 설치 프로그램이 검증된 전용 Python을 다운로드하며, 초기 준비에는 **320 MiB** 여유 공간이 필요합니다. 시스템 Python을 교체하지 않습니다. 복구에 쓰이는 런타임은 보관하세요. [Python 안내(영어)](../OPTIONAL-PYTHON.md). Developer Mode 자동 갱신은 **Beta이며 기본적으로 꺼져 있습니다**. root 없는 TV의 실제 갱신은 확인되지 않았으므로 공식 타이머를 계속 확인하세요.

### Developer Mode 설정 (No-root)

Developer Mode를 사용하면 root 없이 TV에 CYTV 앱을 설치할 수 있습니다.

1. TV에서 LG Apps를 열고 Developer Mode를 검색하여 설치하세요.
2. Developer Mode를 열고 LG Developer 계정으로 로그인하세요. 계정이 없으면 webostv.developer.lge.com에서 만드세요.
3. Dev Mode Status를 켜세요. TV가 재시작되면 Developer Mode를 다시 여세요.
4. Key Server를 켜고 Developer Mode를 열어 두세요. 표시된 IP Address를 CYTV의 TV 주소로 입력하세요.
5. TV의 Developer Mode에 표시된 6자리 Passphrase를 입력하세요. 대소문자를 구분하세요.

LG 계정 비밀번호가 아닌 TV 화면의 코드를 사용하세요. 코드가 보이지 않으면 Key Server를 켜세요.

페어링은 별도 단계입니다. TV에서 요청하면 리모컨으로 CYTV를 승인하세요.

타이머가 끝나기 전에 Developer Mode를 열고 TV가 인터넷에 연결된 상태에서 EXTEND를 누르세요. 만료되면 LG가 이 앱들을 삭제할 수 있습니다.

## 설치와 언어 선택

- **Windows x64:** `cytv-windows-x64-desktop.zip`을 다운로드하고 파일 탐색기에서 **모두 추출**을 선택한 다음 `cytv-desktop/cytv-desktop.exe`를 여세요. `_internal` 폴더를 옆에 그대로 두세요. Windows 게시자 서명은 구성되어 있지 않습니다. 별도 콘솔은 `cytv-windows-x64.exe`입니다. 아래 PowerShell 명령은 이름을 `cytv.exe`로 바꾸고 `.\cytv.exe`로 실행하세요.
- **macOS 13 이상:** Apple Silicon은 `cytv-macos-arm64.zip`, Intel은 `cytv-macos-x64.zip`을 푸세요. `cytv.app`을 응용 프로그램 폴더로 옮겨 열고 로컬 네트워크 접근을 허용하세요. 신뢰할 수 있는 다운로드가 차단되면 개인정보 보호 및 보안 → 확인 없이 열기를 사용하세요. Gatekeeper를 끄지 마세요. 구형 시스템 검증은 완료되지 않았습니다.
- **Linux x64:** Ubuntu 22.04 이상, Debian 12 이상 또는 Mint 21 이상에서 `cytv-linux-x64.deb`를 그래픽 패키지 관리자로 설치하고 앱 메뉴에서 Clean Your TV를 여세요. 라이브러리 설치에 인터넷이 필요할 수 있습니다. Linux ARM 패키지는 없습니다. 독립 실행 파일 `cytv-linux-x64`는 CLI입니다. 그래픽 앱은 `.deb`를 사용하세요.

[Android 설치 프로그램(영어)](../../android/README.md): 오른쪽 위에서 언어를 선택하세요. 앱을 삭제하거나 데이터를 지우지 말고 업데이트하세요. Android 7 / WebView 108은 최소 요구사항이며 검증된 휴대전화 구성이 아닙니다. 승인은 Android 15 ARM64 / WebView 124 에뮬레이터에서 이루어졌습니다. 실제 휴대전화와 실제 TV 연결 복구는 확인되지 않았습니다.

**Android 1.8.2:** 복구 옵션 검토는 명시적 확인 후 원래 저장된 프로필과 SSH 호스트 키로 원래 Root `install / coordinator-submitted` 작업을 읽기 전용으로 검사할 수 있습니다. 앱, 개인 데이터와 기록을 보존하고 프로필 교체나 재설치를 하지 마세요. 검사는 복구를 재개하지 않습니다. [절차와 제한](../../android/README.md#interrupted-root-installation-inspection-unreleased)

데스크톱 설치 마법사는 처음에 시스템 언어를 사용하고 직접 선택한 언어를 저장합니다. TV에서는 **설정 → 언어**에서 언어를 고르거나 시스템 언어를 따르는 자동 옵션을 선택하세요. 설치 프로그램과 TV의 언어 설정은 별개입니다. 지원 코드는 [언어 목록](../LANGUAGES.md)을 참조하세요.

macOS/Linux에서 별도로 받은 CLI는 압축을 푼 폴더에서 실행하세요.

```sh
chmod +x cytv
./cytv --language ko install
```

TV를 선택하거나 IP를 입력하고 에디션과 설치 요약을 확인하세요. 새로운 SSH 신원은 신뢰할 수 있는 네트워크의 본인 TV인 경우에만 승인하세요. 저장된 키가 바뀌면 접근이 차단됩니다. Root는 복구 기능을 준비한 뒤 시험 기간이나 유지 확인 없이 Home을 바로 활성화합니다. 방향키, OK, Home, 뒤로/취소, 음량, 대기 모드 복귀와 전원을 완전히 껐다 켜는 동작을 확인하세요.

**1.6.0:** 패키지 검증, 시작 확인, 실제 Home 버튼 관찰이 별도로 표시됩니다. 실행 요청 확인이나 Helper 프로세스만으로 Home 가로채기를 검증할 수 없습니다. 다른 TV 앱을 열고 Home을 한 번 짧게 누른 후 관찰 결과를 선택하세요. 기본값은 **확인 안 함 / 건너뛰기**입니다. `--yes`는 대신 응답하지 않으며 비대화형 설치는 미확인으로 남깁니다. Home 오류나 건너뛰기는 설치된 패키지를 취소하거나 재설치를 시작하지 않습니다. 도움이 필요하면 로컬 보고서를 저장하세요. 자동 게시되지 않습니다. 다른 조작, 소리, 대기 및 완전 재부팅은 별도 확인이 필요합니다.

## 사용과 복구

방향키로 선택하고 OK로 실행합니다. OK를 길게 눌러 순서를 바꿉니다. 뒤로를 짧게 누르면 앱의 탐색과 종료 확인이 유지됩니다. Home 제어가 활성화되면 짧은 Home으로 런처를 엽니다. 뒤로를 1.2초 동안 누르면 LG Home이 한 번 열립니다. Home 제어 스위치와 설정은 바뀌지 않습니다.

**2초 안에 Home을 세 번 짧게 누르세요.** 매번 버튼을 놓아야 합니다. 설정을 지우지 않고 LG Home으로 복귀하며 Home 제어를 중지합니다. No-root Helper 0.6.13 이하에서는 대신 Home을 약 2초 동안 누릅니다. Home 길게 누르기는 Root의 비상 복구 동작이 아닙니다.

No-root: Home 제어를 다시 시작하려면 Home Helper를 열고 Helper 시작을 선택한 다음 확인하세요. 저장된 Home 화면 선택은 유지됩니다. Root는 Home 설정에서 **Home 변경**을 켜서 재개하세요. **LG Home 열기**는 Home의 연결 대상을 바꾸지 않고 LG Home을 한 번 엽니다. LG Home을 계속 사용할 기본 대상으로 복원하려면 **Home 변경**을 끄거나 `cytv restore`를 실행하세요. 두 제어 프로그램을 동시에 실행하지 마세요. 문제가 반복되면 LG Home을 유지하세요.

미출시 Root 수정: Home 제어를 끄거나 Open LG Home을 선택하면 LG Home의 실행이 확인된 후 Root 창이 닫힙니다. Home 제어를 끈 상태에서도 Home Root를 직접 실행하여 설정을 열 수 있습니다.

> **1.5.4 — Root:** Root가 정상일 때 **Home 변경**을 명시적으로 켜면 TV 입력 목록에 CYTV 소유의 **Clean** 항목을 만들고 기억된 입력을 Clean으로 설정합니다. Home 제어 끄기, 비상 중지, 오류, 업데이트를 위한 일시 중단 또는 제거 시 CYTV의 항목을 삭제합니다. 현재 값이 여전히 CYTV가 설정한 값일 때만 이전에 기억된 입력을 복원하며, 다른 입력과 전면 앱은 유지합니다. 지원되지 않는 TV나 CYTV 소유가 아닌 항목에서는 기존 보호 기능이 적용된 Home 제어를 사용합니다. Clean이 즉시 첫 화면으로 나타난다는 보장은 없습니다. 기록된 C3의 첫 화면, 대기 모드 및 전원 분리 후 시작 검사는 통과했지만 모든 기기의 호환성을 보장하지 않습니다. 업데이트/롤백 후 Home이 꺼질 수 있고(#202), 설정 상태가 오래될 수 있습니다(#206). 설정을 닫았다 다시 열고 Home 변경을 명시적으로 켠 뒤 Clean 상태를 확인하세요. [1.5.4 QA (English)](../history/2026-10-31-release-1.5.3-signed-root-qa.md) · [Native input (English)](../development/ROOT-NATIVE-INPUT.md).

./cytv --language ko status

> **1.6.0 (#152):** Helper 비활성화가 거부되면 No-root 복원/제거 과정에서 검증된 SSH 중지를 사용할 수 있습니다. 중지 상태를 유지하며 결과가 불확실하면 작업 기록도 보존합니다. 상태 파일을 삭제하지 마세요. EF950V 실기기 확인은 아직 필요합니다. [#152](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/152)

> **1.6.0 (#201):** No-root 상태 확인은 중단된 설치/제거 기록을 보존합니다. 파일이 일치하거나 앱이 없어도 작업 완료를 입증하지 못합니다. 검증이 거부되면 중단하고 진단을 보관하세요. 파일만으로 검증을 우회하는 방법은 없습니다. [#201](../RECOVERY.md#unreleased-uncertain-no-root-package-operations-201)

작업이 중단되면 재시도 전에 `status`를 실행하고 로그를 보관하세요. `restore`는 앱을 삭제하지 않고 LG Home을 복구합니다. `uninstall`은 복구 후 제거합니다. Root 복구 데이터는 의도적으로 남습니다. 재설치를 강제하려고 삭제하지 마세요. 진단 보고서는 공유 전에 검토하고 키나 프로필 폴더는 공개하지 마세요.

**Home 설정 → 화면 꾸미기 → 열 수**에서 1~8열을 선택하거나 **테마에 따름**으로 테마의 값을 사용하세요(Classic 기본값: 5). 직접 선택한 숫자가 테마보다 우선합니다. 고정 레이아웃 테마에서는 열 수 옵션이 숨겨지고 제작자의 값이 사용됩니다. 이 설정을 지원하는 테마로 바꾸면 저장된 선택이 다시 적용됩니다. 다운로드한 Alpine 테마의 앱은 하나의 순환 가로 띠로 표시됩니다. 왼쪽/오른쪽으로 순환하고, 위로 바로가기를 열며, 아래로 같은 앱에 돌아옵니다. Alpine에서는 마우스 휠이나 터치패드로도 띠를 스크롤할 수 있습니다. 대화상자가 열려 있으면 뒤의 Home은 움직이지 않습니다.

1.5.4: **Home 설정 → 화면 꾸미기**의 **앱 추가 타일 표시**를 끄면 + 타일을 숨길 수 있습니다. 기본값은 켜짐입니다. +를 숨겨도 같은 화면의 **앱 추가**로 앱을 추가하거나 다시 표시할 수 있습니다. 앱 이동과 숨기기는 계속 사용할 수 있으며 선택은 다시 시작한 후에도 유지됩니다. 모든 앱을 숨겨도 상단 버튼과 설정은 사용할 수 있습니다.

1.7.0: 선택한 테마가 상단 **입력** 메뉴 또는 HDMI 선반을 결정합니다. 전역 위치 설정이나 **Home에 입력 표시** 스위치는 없습니다. 선반은 현재 `dock-grid`만 지원합니다. Liquid Glass는 선반을 선택하며, Classic과 이 옵션이 없는 테마는 상단 메뉴를 유지합니다. 독에서 위를 누르면 선반, 다시 위를 누르면 상단 버튼으로 이동합니다. 아래 또는 뒤로는 독으로 돌아가며 OK는 입력 소스를 실행합니다. 소스 타일이 있으면 선반이 상단 입력 메뉴를 대체합니다. 기기 이름은 펌웨어가 제공하는 입력 메타데이터에서만 가져오며, 없으면 연결된 소스에 **연결됨**을 표시합니다. Home은 PlayStation 이름을 만들어 내거나 CEC 식별을 보장하지 않습니다. 빈 포트도 선택할 수 있습니다. 미리보기는 **기본적으로 켜져 있습니다**. 사용자가 명시적으로 저장한 끄기 설정은 유지됩니다. 미리보기를 끄려면 **Home 설정 → 화면 꾸미기 → 선택한 입력 미리보기**를 끄세요. 켜져 있고 선택한 테마에 선반이 있을 때 연결된 HDMI에 약 0.8초 머물면 미리보기가 표시될 수 있습니다. 일부 TV에서는 HDMI 미리보기가 소리를 재생하거나 HDR을 켤 수 있으며 무음은 보장되지 않습니다. Home은 TV의 전역 음소거 또는 HDR 설정을 자동으로 변경하지 않습니다. Live TV와 빈 포트는 정적 타일을 유지합니다. Root는 자체 서비스를 통해 입력 상태를 읽습니다. No-root는 허용되는 경우 직접 EIM을 사용하며, 권한이 거부되면 이미 페어링된 Helper를 통해 읽기 전용으로 요청합니다. 읽기에 실패하면 상태는 알 수 없음으로 남으며 새 설정이나 페어링 요청은 추가되지 않습니다.

1.5.4의 선택적 사이드바 레이아웃 테마 미리보기에서는 위/아래로 메뉴 항목을 선택하고, 오른쪽으로 앱으로 이동하며, 앱의 첫 번째 열에서 왼쪽을 누르면 메뉴로 돌아갑니다.

No-root 1.5.0: 대기 모드 해제 후 일시적인 watchdog 시간 초과가 발생하면 Helper가 10분 동안 최대 5회 복구를 시도합니다. Stop과 Home 세 번 누르기 후에는 여전히 Helper를 명시적으로 시작해야 하며, 오류가 반복되면 중지 상태를 유지합니다. TV 검증은 아직 완료되지 않았습니다. [동작과 제한 사항(영어)](../HELPER-DIAGNOSTICS.md#watchdog-recovery-unpublished-candidate-155).

## 업데이트와 제거

연결 후 cytv는 설치 버전 → 포함 버전을 표시하고 최초 설치, 재설치, 이전 버전 설치를 구분합니다. 확인 전에 요약을 읽으세요. `--yes`를 사용해도 호환성 검사는 유지됩니다. 작동하는 패키지와 설정의 비공개 복사본을 보관하세요. 컴퓨터에서 패키지를 바꾸기 전 No-root Helper를 중지하고, 먼저 제거하지 마세요. 실행 중인 Root에 IPK 하나만 덮어쓰지 말고 cytv의 정해진 절차를 사용하세요. 데스크톱 앱 제거는 TV 앱을 제거하지 않습니다.

Home 설정 → 소프트웨어 업데이트에서 제시된 버전을 확인한 뒤 승인하세요. TV에서 업데이트와 롤백을 하려면 No-root 에디션도 **root, Homebrew Channel**과 미리 준비한 호환 업데이트 구성요소가 필요합니다. root가 없으면 컴퓨터를 사용하세요. 전체 시스템 업데이트 준비는 별도로 명시적으로 실행합니다. [업데이트(영어)](../UPDATES.md). 복구 화면에서 저장된 롤백 버전을 확인하세요. 롤백하면 이후 설정 변경이 사라질 수 있습니다.

**기존 1.3.0 설치:** 원래 System Updater는 변경된 인프라를 거부할 수 있습니다. 중단된 작업을 보존하고 1.5.0+ 문서의 검증된 복구 및 교체 준비 절차를 따르세요. 기록을 삭제하거나 무작정 재시도하지 마세요. 앱만 업데이트하면 고정된 Root 인프라는 교체되지 않습니다. [이전과 복구(영어)](../UPDATES.md#one-time-computer-preparation).

Home 설정 통신 경로 수정은 1.5.0에 배포되었습니다. 호환되는 공개 설치 프로그램으로 Home과 Helper를 함께 업데이트하세요. Home만 업데이트하면 Helper는 바뀌지 않습니다. 검증 범위는 기록된 모델로 제한됩니다. [#146](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/146).

Root HDMI 소리 복구는 실험적이며 **기본적으로 꺼져 있습니다**. 필요할 때만 켜세요. 정상적인 소리를 끊을 수 있으며 eARC 호환성이 확인된 것은 아닙니다. [소리 복구(영어)](../development/ROOT-AUDIO-RECOVERY.md). 별도 **Homebrew CYTV Installer는 아직 출시되지 않았습니다**. 공개된 컴퓨터 또는 Android 설치 프로그램을 사용하세요.

Homebrew Channel이 이 설치 프로그램의 접근을 거부했습니다. webOS 11에서는 Homebrew 0.7.3에 개발자의 호환성 업데이트가 필요합니다. 수정 사항이 포함된 지원 Homebrew 버전이 나올 때까지 공개된 컴퓨터 또는 Android 설치 프로그램을 사용하세요. [#116](https://github.com/Razdva122/clean-your-tv-lg-webos/issues/116).

1.5.0+: 이전 Root 디렉터리의 쓰기 권한 때문에 펌웨어 API 접근이 거부되면 `cytv enable-firmware-access --edition root --repair-package-permissions` 명령이 신뢰할 수 있는 비공개 패키지 기록으로 현재 파일을 검증한 뒤 Root 소유 경로의 그룹 및 기타 사용자 쓰기 권한만 제거합니다. 알 수 없거나 변경된 파일이 있으면 중단합니다. 프로필, Home 선택 및 펌웨어 차단 설정은 유지됩니다. [세부 정보(영어)](../LG-FIRMWARE-UPDATES.md#explicit-package-permission-repair-candidate).

1.5.0+: `cytv recover-system-rollback --edition root`는 검증된 Root 롤백에서 모든 패키지 설치가 끝났지만 런처 준비 시간이 초과된 경우에만 사용합니다. 실제 런처의 준비 신호가 필요하며 설치 결과가 불명확하면 거부합니다. 패키지, 고정된 코드·키, 실패 증거와 명시적으로 끈 Home 제어 상태를 보존합니다. 제한된 시도를 비공개 기록으로 남깁니다. 일반 재시도는 기한을 연장하지 않습니다. 이전 120초 기한이 지난 뒤 승인된 준비 신호나 불명확한 설치 결과가 없을 때만 `--new-recovery-attempt`가 이전 기록 전체를 UUID/해시로 보관하고 명시적으로 새 시도를 시작합니다. 완료된 복구는 다시 시작하지 않으며 자동 반복 시도는 없습니다. [절차와 제한 사항(영어)](../RECOVERY.md#root-system-rollback-readiness-candidate).

1.6.0: System Updater 1.2.0은 허용된 새 설치 또는 `cytv replace-system-updater --edition root`를 통한 검증된 1.1.0/1.1.1 교체용입니다. System Updater만 교체하며 Root/Root Updater 앱, 전체 프로필과 Home 선택을 보존하고 이전 상태를 보관합니다. 알 수 없거나 끝나지 않은 작업이 있으면 교체가 중단됩니다. 설치된 1.1.2는 기존 채널에 고정되며 일반 마이그레이션은 제공되지 않습니다. 강제로 교체하지 마세요. 이 조건은 No-root 피드를 제한하지 않습니다. [교체 절차(영어)](../RECOVERY.md#replace-the-root-system-updater-candidate)

## 도움말과 자세한 안내

**1.6.0:** 저장된 동일한 TV에서 **복구 옵션 확인**을 선택하거나 `cytv recover`를 실행하세요. 확인과 변경은 별도로 승인해야 하며 기본값은 아니요입니다. `--yes`로 승인할 수 없습니다. Root는 기존 검증 후에만 계속합니다. No-root는 기존 패키지 서비스 검사가 허용할 때만 제거를 제안하며 Home 설정이 초기화될 수 있습니다. 새 설치는 자동으로 시작되지 않습니다. 상태를 알 수 없거나 접근이 거부되면 보고서를 저장하고 중단하세요. 기록을 보관하고 제거를 반복하지 마세요. #201의 완료 증거와 #216의 실제 TV 복구는 여전히 확인되지 않았습니다. [Recovery](../RECOVERY.md). 도움을 요청할 때 모델, 펌웨어, 에디션, 설치 프로그램 버전, 실패 단계, 예상 및 실제 동작을 적고 보고서의 비밀 정보를 제거한 뒤 공유하세요.

미출시: Root 활성화 실패 후 같은 저장된 연결에서 복구를 확인하세요 (`cytv recover`). LG Home 복원, 제어 비활성화, 패키지/updater 검증 후 별도 확인으로만 계속할 수 있습니다. 기록을 보존하고 재설치하거나 failsafe 표시를 삭제하지 마세요. [Recovery](../RECOVERY.md#failed-root-activation-unreleased).

1.7.0: 원본 기록으로 확인되는 경우, 첫 패키지 요청 전에 중단된 No-root 삭제는 전체 패키지 상태 권한 없이 복구를 계속할 수 있습니다. 삭제를 별도로 확인하고, 삭제 검증 후 설치를 따로 시작하세요. 결과가 불명확하거나 이미 전송된 작업은 계속 차단됩니다. 저장된 연결과 기록을 보존하세요. 1.6.0에는 포함되지 않습니다. [자세히](../RECOVERY.md#no-root-removal-stopped-before-package-submission-unreleased).

## 테마

1.8.2의 **Home 설정 → 배경화면**에서 현재 테마의 배경화면, 감지된 TV 기능과 현재 모드를 확인할 수 있습니다. 자동은 호환되는 품질을 선택하며, 4K·1080p·이미지는 테마에 포함된 경우에만 사용할 수 있습니다. 재생에 실패하면 이미지로 전환됩니다. 밝기 감소는 5%씩 조절하거나 테마 기본값으로 복원할 수 있습니다. Classic과 배경화면이 없는 테마는 해당 상태가 명확히 표시됩니다.

1.8.2의 개인 배경화면: 데스크톱 CYTV에서 배경화면을 열고 JPG/PNG를 선택한 뒤 자르기를 조정하고 Home 설정에 표시된 TV의 사설 주소와 수신 PIN을 입력하세요. CYTV는 로컬에서 무음 동영상을 만들며 자른 원본의 해상도가 충분할 때만 4K를 제공합니다. TV에서 CYTV 수신 또는 휴대폰 업로드를 선택하고 같은 Wi-Fi에서 QR을 스캔하세요. 휴대폰은 네이티브 4K 동영상 레이어 없이 최대 1920×1080의 일반 이미지를 전송하며 선명도는 TV 인터페이스 해상도로 제한됩니다. 전송 전 경고를 확인한 뒤 TV에서 미리보고 적용하세요. 개인 업로드는 저장되며 배경화면에서 다시 선택하거나 삭제할 수 있습니다. 취소되거나 거부된 파일은 기존 배경을 유지합니다. 1.8.2 이상의 호환되는 Home/서비스 및 CYTV 빌드가 필요합니다.

개인 동영상(1.8.2): 데스크톱 CYTV → 배경화면에서 1~60초, 최대 512 MiB 및 3840×2160의 MP4/MOV/MKV/WebM을 선택합니다. 소리는 제거되고 중앙 16:9로 잘립니다. 작은 동영상은 호환되는 1080p로 출력되며 UHD는 원본 크기가 충분할 때만 생성됩니다. TV 주소/PIN으로 보낸 다음 TV에서 확인하고 적용하세요. 휴대폰 업로드는 JPG/PNG만 지원합니다. 실제 TV 검증 범위는 제한적입니다. [1.8.2](../RELEASE-1.8.2.md)를 확인하세요.

1.8.2의 기본 배경화면: **Home 설정 → 배경화면 → 기본 배경화면 → Black Hole**. 동영상 제작자는 **Xecutioner**이며 출처를 표시하는 비상업적 이용을 허가받았습니다. 다른 테마를 확정하면 해당 테마의 배경이 적용되며 Black Hole과 개인 업로드는 다시 선택할 수 있습니다. 연속 4K 스트림은 반복 때마다 되감는 동작을 없애며 호환 동영상/이미지로 대체할 수 있습니다.

Android CYTV: **TV 설정** · **배경화면** · **유지 관리**. TV에서 Home 설정 → 배경화면 → 휴대전화에서 업로드를 여세요. 휴대전화 카메라로 QR 코드를 스캔하고 JPG/PNG를 선택한 후 TV에서 적용하세요. 휴대전화: 최대 1920×1080 이미지이며 네이티브 4K 동영상은 지원하지 않습니다. 실제 4K는 컴퓨터의 CYTV를 사용하세요.

1.7.0: **설정 → 테마**를 여세요. **Classic**, **Liquid Glass**, **Ribbon**은 내장되어 테마 다운로드가 필요하지 않으며 기본값은 Classic입니다. **Channel**은 showcase의 외부 테마입니다. 갤러리 시험에서는: 선택 후 **20초** 안에 **테마 유지**를 누르세요. **되돌리기**, Back 또는 시간 초과 시 이전 테마로 돌아갑니다. 확인 전에 Home이 종료되면 다음 실행에서 Classic으로 복구됩니다. 설치 목록의 내장 및 다운로드 테마는 확인 타이머 없이 즉시 적용되고 저장됩니다. 컴퓨터에서 받거나 URL로 설치한 테마도 같습니다. 갤러리 안의 테마 시험만 20초 시험을 시작하며 이미 다운로드된 버전도 동일합니다.

1.7.0: **Classic**, **Liquid Glass**, **Ribbon**이 내장됩니다. **Alpine 1.4.4**는 **테마 갤러리**에서 다운로드하는 테마로 이동합니다. 저장된 `builtin:alpine` 선택은 기존 복구 알림을 표시하고 Classic으로 돌아갑니다. Home은 Alpine을 자동으로 다운로드하거나 Liquid Glass로 바꾸지 않습니다. 버전 1.6.0에는 Classic, Alpine, Ribbon이 포함되어 있습니다.

설치된 테마는 가로로 스크롤되는 한 줄에 표시됩니다. 활성 테마는 항상 맨 앞에 있으며 카드가 강조 표시됩니다. 왼쪽/오른쪽 버튼으로 테마를 탐색하세요.

갤러리에는 이 TV에 설치되지 않은 테마만 표시됩니다. Classic, Liquid Glass, Ribbon 및 다운로드한 테마는 새 버전이 있어도 숨겨집니다. 삭제한 테마는 다시 표시됩니다. 업데이트는 URL 또는 컴퓨터 전송으로 설치하세요.

테마 카드는 설정 카테고리 옆 테마에 바로 표시됩니다. 갤러리, 링크 설치 및 컴퓨터 전송도 같은 패널에서 열립니다. 갤러리 시험 중에만 Home이 잠시 표시됩니다.

갤러리를 열거나 새로 고침을 선택하면 Home 업데이트나 페이지 다시 로드 없이 기본 프로젝트 저장소에서 검토된 카탈로그 업데이트를 확인합니다. 일반 병합 후 새 항목을 사용할 수 있으며 병합 전 후보에서는 내장 카탈로그가 표시될 수 있습니다. 오프라인이거나 오류가 발생하면 내장 항목과 미리보기를 사용합니다. 내장 테마는 설치된 Home 버전과 일치합니다. Channel 미리보기를 열고 **테마 다운로드**를 선택하세요(인터넷 필요). 다운로드 후 시험하고 **20초** 안에 테마 유지를 선택하세요. 설치된 테마는 오프라인으로 작동합니다. 고정 링크용 URL 추가도 계속 사용할 수 있습니다.

미공개 테마를 시험하려면 먼저 TV에서 **설정 → 모양 → 컴퓨터에서 받기**를 여세요. TV에 표시된 주소와 6자리 PIN을 컴퓨터 미리보기의 **Send to TV**에 입력하고 전송한 뒤 TV에서 **테마 적용**을 선택하세요. 기본 방식은 PC에서 TV의 TCP **8879**로 연결하므로 컴퓨터 방화벽을 변경할 필요가 없습니다. 두 기기는 신뢰하는 동일한 홈 네트워크에 있어야 합니다. 수신기는 한 번의 업로드, 취소, 화면 이탈 또는 **10분** 후 닫힙니다. PIN은 저장되지 않으며 설치된 테마는 오프라인에서도 작동합니다. GitHub 공개는 필요하지 않습니다.

게시된 테마는 **ID로 추가**에서 ID(예: `102300a209`), `da.gd/102300a209` 또는 전체 GitHub 링크를 입력하세요. Home은 로드 전에 da.gd 주소를 표시하고 GitHub 대상과 테마 패키지를 검증합니다. 작성자는 릴리스 노트 또는 컴퓨터 미리보기의 **TV link → Copy ID**에서 ID를 복사할 수 있습니다.

**1.6.0:** Home Helper 패널의 **진단 보기**는 패널 자체 상태 요청의 필터링된 결과를 보여 줍니다. 보기만으로 Helper가 시작되거나 Home 제어가 변경되지 않습니다. 요청을 받으면 검토한 JSON만 공유하세요. [자세한 내용](../HELPER-DIAGNOSTICS.md#candidate-panel-caller-diagnostics-207).

[Themes (English)](../THEMES.md) · [1.5.4 QA (English)](../history/2026-10-31-release-1.5.3-signed-root-qa.md).

아직 출시되지 않은 맞춤 리본 테마는 입력, Wi-Fi, 설정을 왼쪽 아래에 배치할 수 있습니다. 이 탐색을 사용하면 첫 번째 보이는 앱에서 왼쪽으로 설정, Wi-Fi, 입력 순서로 이동하고 설정에서 오른쪽을 누르면 같은 보이는 앱으로 돌아갑니다. 새 Home 기능이 필요한 테마는 미지원 버전에서 설치가 거부되며 현재 모양과 선택은 유지됩니다. 먼저 Home을 업데이트하세요. 이후 버전을 낮추면 시작 시 Classic이 복구될 수 있습니다.

테마에는 기본 테마와 직접 설치한 모든 테마의 미리보기가 오프라인에서도 표시됩니다. 별도 버튼으로 공개 테마 목록을 엽니다. 개인 설치는 테마를 공개하지 않습니다.

화면 꾸미기에는 현재 개수가 표시되는 열 수와 앱 설정이 있습니다. 별도 테마 카테고리에는 설치된 테마, 갤러리, 컴퓨터에서 받기, 오른쪽의 ID로 추가가 있습니다(예: 102300a209). Classic 카드로 복원하고 다운로드한 테마는 개별 삭제하세요. 언어 카테고리에서 바로 언어를 선택합니다.

브라우저 미리보기의 컴퓨터에서 받기는 TV에서 할 작업을 설명하며 컴퓨터에서 TV 수신기를 시작하지 않습니다. 미리보기 위의 Send to TV를 사용하세요. 다운로드한 테마를 삭제하려면 확인이 필요합니다. 활성 테마를 삭제하면 먼저 Classic이 복원됩니다. 취소하면 테마가 유지됩니다.

## 설정 카테고리 (1.5.4)

두 에디션 모두 왼쪽에 카테고리, 오른쪽에 선택한 설정이 표시됩니다: 홈 화면, 화면 꾸미기, 테마, 언어, 소프트웨어 업데이트, 고급. No-root에는 Developer Mode가 추가됩니다. Root의 LG 펌웨어 업데이트는 업데이트에, HDMI 사운드는 고급에 있습니다. 위/아래는 열 안에서 이동하고 오른쪽은 설정으로, 왼쪽은 카테고리로 이동합니다. 뒤로는 먼저 카테고리로 돌아간 다음 설정을 닫습니다. Tab으로 Home 복귀 버튼에도 이동할 수 있습니다.

소프트웨어 업데이트 카테고리와 내부 버튼의 노란 점은 업데이트가 있음을 뜻합니다. 정상적인 확인으로 업데이트가 없다고 판명되면 둘 다 사라지며, 확인 실패 시 마지막으로 확인한 상태를 유지합니다.

## 자동 그래픽 해상도 (1.6.0)

1.6.0 컴퓨터/Android 설치 프로그램과 마이그레이션된 OTA 클라이언트는 TV가 보고한 기능에 따라 720p 또는 1080p를 선택합니다. 확인할 수 없으면 작업이 중단됩니다. 별도로 설치된 구형 업데이트 도구는 문서에 나온 컴퓨터 마이그레이션이 필요하며, 복구는 원래 패키지를 유지합니다.

[HD/FHD details (English)](../development/HOME-GRAPHICS-RESOLUTION.md#automatic-selection-and-ota).

> **1.6.0:** 처음 실패한 시도의 보고서를 보관하세요. 새 보고서는 기록된 첫 오류와 이후 점검을 구분하고 필터링된 Doctor/상태 요약을 포함합니다. 설정, 상태 확인 또는 복원이 성공한 뒤에도 보고서를 내보낼 수 있습니다. 없는 과거 증거는 알 수 없음으로 남으며, 보고서가 복구 작업을 허용하지는 않습니다. [↗](../development/INSTALLER-DIAGNOSTICS.md).

## 저장 공간

후보 빌드는 설치, 테마 및 개인 사진/비디오 배경화면에 필요한 공간, 여유 공간과 부족 공간을 MiB로 표시합니다. 임시 복사본과 예비 공간을 포함합니다. 앱 할당량, 64 MiB 테마 캐시 및 비디오 캐시는 별도 제한입니다. 알 수 없는 값은 명시합니다. 표시된 저장 공간만 확보하세요. 자동 정리는 하지 않습니다.

공간 예상 (TV): 필요 128.0 MiB; 여유 96.0 MiB; 부족 32.0 MiB.


후보 버전: Root 활성화를 거절한 뒤 별도로 확인하면 LG Home과 Home 제어가 꺼진 상태로 검증된 설정을 완료할 수 있습니다. 패키지와 복구 데이터는 보존됩니다. 전체 시스템 업데이트는 별도로 준비하세요. 런처만 업데이트하면 런타임은 업데이트되지 않습니다. [↗](../RECOVERY.md#candidate-finish-verified-root-setup-with-home-control-off).
