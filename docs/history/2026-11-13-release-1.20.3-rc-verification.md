# v1.20.3 candidate verification on the project C3

The [full candidate build](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/43405375772)
passed as attempt 1 from `09ef047afeb44ab5a2cda2544c2b18c70fc8ed8e`.
The project LG OLED55C3RLA ran firmware 43.21.71 and webOS SDK 11.2.0.
The installer ran on macOS ARM64. The starting versions were Root 0.17.0,
Root Updater 0.5.9 and System Updater 1.2.9. No-root Home and Helper were
absent, both saved installer profiles were idle, and Change Home was off.
A current live UI profile and a verified local recovery archive were
preserved before any package changes.

The exact installer executable SHA-256 was
`d9d17941aef9a23c0ae42e3d6be989b6255f0825de52bf4c9a8ed3f55b91d59b`.
The [protected Root QA signing run](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/43409721597)
produced the Root envelope with SHA-256
`e702920dcb9f3bd68535679770fb6db4bef488f93ad2d41d392538615e8d5b18`.
All three signed components matched the embedded installer bytes.
See [PR #597](https://github.com/Razdva122/clean-your-tv-lg-webos/pull/597)
for platform artifact hashes and Android emulator results.
