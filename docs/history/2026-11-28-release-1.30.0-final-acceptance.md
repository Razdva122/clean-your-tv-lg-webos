## Doctor correction and package comparison

RC2 Doctor reported `unavailable` on the Root installation. A passive probe
found one matching input with both advertised bits. Nineteen other character
nodes returned `ENXIO` and had no matching sysfs registration. The correction
skips that specific state while keeping uncertainty from permissions, a
missing registry or a present registry entry. No input events were read.
The corrected probe passed on the same C3 firmware in the frozen RC3
installer. [Correction PR](https://github.com/Razdva122/clean-your-tv-lg-webos/pull/876)

The RC2 and RC3 installers have different archive hashes. All 636 embedded TV
files, 521 other bundled Python modules,
the entrypoint and the other unpacked runtime entries matched by bytes.
`cytv.doctor_mrcu` was the only changed Python module. The identical
installation, cleanup and Debloat inputs support reusing A01, A02 and A04
without reinstalling on C3. The FHD Root package and its corresponding
startup and routing inputs also matched.
