# v1.20.4 candidate verification on the project LG C3

The [full candidate build](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/43454675248)
passed as attempt 1 from `58ceffd04ba3596f65f309b5ddb04e5ad68e5c4e`.
The LG OLED55C3RLA ran firmware 43.21.71 and webOS SDK 11.2.0.
The installer ran on macOS Apple Silicon. Starting versions were Root 0.17.0,
Root Updater 0.5.9 and System Updater 1.2.9. No-root Home and Helper were absent.
Both installer profiles were idle. Change Home was off.

The macOS installer executable SHA-256 was
`980583ab5b5c70775523594bfaf7761f07ac1bc3cc02a9076de4852dc8d5b358`.
All 599 embedded payload files passed verification. The
[protected Root QA signing run](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/43464596570)
produced envelope SHA-256 `dd8dbea4c4f169c9f49966a455769830f70a33e96143edf1d0aa67c3764c7e90`.
The production signature verified, and all three signed package hashes matched
the exact embedded installer payload.
