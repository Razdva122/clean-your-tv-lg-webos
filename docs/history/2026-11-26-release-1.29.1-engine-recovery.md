# v1.29.1 System Updater Engine acceptance

v1.29.0 assembled but remained unpublished. Its protected signer rejected an
Engine 1.2.16 with modified Luna support from #831. The [RC4 device evidence](2026-11-26-release-1.29.0-rc-verification.md)
and [original release ledger](https://github.com/Razdva122/clean-your-tv-lg-webos/pull/827)
describe both the accepted device scope and the failed publication.

The complete [replacement build](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/45761587837)
passed on attempt 1 from source `1337f4c6181ce68365c52858423a82f189c63734`. The macOS ARM64
CLI SHA-256 is `fc87c6946ea5ec5aab54fc96598250134b2744e48abaca6f5c7543dfa7b3c40c`. Its local runtime test passed and its
payload verifier authenticated all 634 entries. Of those entries, 631 match
the accepted RC4 byte for byte. The other entries are the two Engine bundle
manifests and the legacy nested payload manifest. Only the engine version and
the corresponding integrity hash changed. Home, Helper, Ambient, relay,
installer/recovery code and the Root application packages kept the exact
previous bytes.

(P00, A01, A02 and A04) reuse the original receipt. A05 and A06 passed their
