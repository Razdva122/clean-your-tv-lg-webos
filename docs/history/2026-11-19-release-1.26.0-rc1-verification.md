## Local Helper compatibility probe

Project TV LG OLED55C3RLA, firmware 43.21.71, webOS SDK 11.2.0. The Mac ARM64
source installer used the saved No-root Root SSH connection and paired
network remote. The physical remote model was unavailable for this probe.

- Starting state had published Root 0.22.0 with active Home intent and guardian,
  no Home/Helper packages and idle installer receipts. Selected Root files
  matched the published IPK. Root Home app-origin data was saved and verified
  privately before switching editions. The published installer restored LG Home,
  then completed Root cleanup after a verified software restart.
- Ordinary setup installed published Home 1.20.4 FHD with candidate Helper
  0.9.3. Selected app and service bytes matched the packages and receipts
  were idle. The Helper controller was already running. The published Home
  Start Helper command succeeded, and the Renewal service returned enabled
  Home status and a successful app catalog response.
- One network HOME from Media Player briefly visited LG Home, opened
  `com.gathin.tvhome` and held it for one second. Ordinary No-root Restore
  returned the same network route to LG Home.
- The exact canonical Helper archive and published rollback hashes were recorded
  in `native/helper-rollback-compatibility.json`, then passed
  `verify_helper_transition` and release-manifest verification.

- The probe packages were removed after the installer requested a verified
  software restart. The published v1.25.0 installer reinstalled Root 0.22.0.
  Selected package files and Root Home app-origin data matched readback.
  Active Root intent, guardian, SAM Home and idle installer receipts verified.
  Network HOME reached Root Home and both temporary No-root apps were absent.

HD was authenticated offline. No physical Magic Remote, sound, standby, AC
cold boot, OTA or model-specific EF950V and webOS 4.5 behavior was tested.
The probe precedes the complete RC and does not establish final acceptance.

## RC1 browser failure

[Run 44497133853](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/44497133853)
built source `48ad3e4f080c93144c6144f0ca069314d571cae1`. The full browser
matrix failed in [theme shard 3](https://github.com/Razdva122/clean-your-tv-lg-webos/actions/runs/44497133853/job/135467410322).
The Columns fixture loaded the edition stylesheet alone. #732 had moved the
shared flex and spacing declarations into `launcher/settings-panel.css`.
Local Chromium reproduced the same `block` versus `flex` assertion.

[PR #737](https://github.com/Razdva122/clean-your-tv-lg-webos/pull/737) adds the
shared stylesheet before the edition stylesheet, matching both packaged entry
points. Chromium passed the original geometry, focus, navigation and
accessibility assertions for both editions at all three viewport sizes.
Prettier and `git diff --check` passed. All eleven later tests in the shard,
which CI had stopped before running, passed in local Chromium. The release input
verifier includes this test file in its snapshot, so the replacement requires
its own complete run.

RC1's Android artifact matched its GitHub archive hash, signer report and
frozen source. The 620 embedded entries and the C3-tested Helper canonical
archive verified. This result stays attached to RC1.
