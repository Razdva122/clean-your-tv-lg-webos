## Lifecycle refresh correction and 0.8.2 re-freeze

[PR #263](https://github.com/Razdva122/clean-your-tv-lg-webos/pull/263) extends
serialization across visibility and webOS relaunch refreshes. Each refresh still
invalidates older generations immediately, but all read pairs share one promise
queue; queued stale/hidden requests perform no service work. In-flight stale
responses cannot unlock controls. Source and Home reads remain serial, with
source-failure advice retained. Mutations are neither queued nor retried.

The actual-handler lifecycle regression failed before the correction and passed
after it. Focused settings/service/startup tests, the complete local UI group
and the Chromium Root Settings browser regression passed. Independent review

app/service 0.8.2 versions. A new full build, original-key signed set and affected
exact-package acceptance are required.
