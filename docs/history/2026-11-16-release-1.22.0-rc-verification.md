## Root supervisor migration preflight

The macOS ARM64 installer matched the published v1.21.0 SHA-256 and set up
Root 0.20.0, Root Updater 0.5.17 and System Updater 1.2.9 on the project C3.
A single network HOME from Media Player verified active CYTV Home before the
first replacement probe. The rendered Root profile and retained files were
backed up privately before any supervisor change.

1. The first command refused before mutation because full uninstall and fresh
   bootstrap had left a completed replacement journal with its earlier archive
   already removed. The fix distinguishes the current terminal bootstrap from
   that older history, verifies the live package and code, and preserves the
   historical proof. The installer still refuses incomplete or inconsistent
   evidence.
2. The next command installed System Updater 1.2.10 and verified the Root bytes.
   The active route fell back to LG Home while the original profile remained
   intact. Exact Home verification stopped the operation at verify. The current
   package, previous archive, installed Root, real UI capture and recovered
   effective LG Home were independently checked. The coordinator closed the
   preliminary operation as recovered to stock and recorded the unsuccessful
   Home result. The stock network HOME route then passed independently.
3. Replacement now starts only after explicit installer Restore confirms LG
   Home. During provisioning or resume it refreshes LS2 registration without
   forcing a launcher restart. The finished replacement can also participate
   in ordinary verified cleanup, whose existing nonterminal safeguards still
   apply. The focused check returned to a clean published v1.21.0 baseline
   to exercise the updated command.
4. Standard cleanup after a completed replacement first refused because the
   product coordinator did not recognize the terminal replacement owner.
   The focused fix accepts only a matching terminal journal. Ordinary cleanup
   then passed after the required software reboot and verified LG Home.
5. Reinstalling the published baseline left a newer completed bootstrap and
   an older record for the same deterministic replacement bundle. The first
   retry refused before mutation. A regression check reproduced it and the
   installer now distinguishes that older record from the live supervisor.
   On 2026-11-16 at 18:53 +05:00 the repaired command installed System Updater
   1.2.10, retaining Root 0.20.0, Root Updater 0.5.17 and the exact rendered
   launcher profile. Network HOME from Media Player stayed on LG Home for a
   second after the change. This verifies the source migration, pending
   comparison with the final full RC package.
