# 1.10.0 final acceptance — 2026-11-07

## Accepted scope and decision

The maintainer authorized publication after verification of the installer and all
included fixes, and explicitly declined additional physical acceptance of the
remaining paths in this release session. The accepted scope below is bounded;
untested paths are not passes and no universal TV/phone compatibility is claimed.
There is no outstanding observed failure in the tested installer/recovery scope.
Original issue causes and individual reporter recoveries remain separate.

One release coordinator froze the 14-PR inventory and dispatched one replacement
full candidate after the consolidated fix batch, focused regressions, independent
review and the newly reachable device cases. No new feature PR was admitted.

## Explicitly untested / deferred scope

The maintainer accepted release without extending this session to pristine
No-root Developer Mode hardware, a physical Android phone/minimum WebView,
physical AC disconnection/cold boot, OTA/retained rollback in the new cycle,
C1 Beta reinstallation (unsupported fresh-only), or additional pointer/wheel and
multi-app matrices. These paths are **not tested/passed by this record**.
Historical records retain their original versions and conditions. Retained
System1.1.2 receives no general supervisor migration, and original reporter
recoveries remain unconfirmed. The release decision does not close those reports.
