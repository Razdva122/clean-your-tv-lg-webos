## RC-02 Helper compatibility on the C3

Project LG OLED55C3RLA, firmware 43.21.71, webOS SDK 11.2.0,
macOS ARM64 source cytv 0.20.9 and the saved No-root connection over Root
SSH. Physical remote model unknown. The C3 started with Home 1.18.6,
Helper 0.8.5, stopped Home control and no pending receipt for either edition.

| Package | SHA-256 |
| --- | --- |
| Published Home 1.18.7 FHD | `29e2df15b6daa5e825cbe7a923f7e2e625041d1b05ea8ef684044fb61688f70d` |
| Published Home 1.18.7 HD | `9c435bbe5c33af47b49e3a7dd44359b8810cf319ee040dd9fc139cd0244e6e20` |
| Published Helper 0.8.6 | `a7257e70314207513634785c4a958da577bf8018ee6a06438d121c4793968f9f` |
| Source Helper 0.8.7 | `1d329657d9232763c1fd7cfa8b3ab7ac7ef46f4b296d75148caba902953a8839` |
| Source Helper 0.8.7 canonical archive | `d51a565fa366b947798a07dd4c05b79f1138ac10dd3fff8af6381b2cffb72962` |

The ordinary installer installed published FHD Home 1.18.7 and source Helper
0.8.7, retaining Stop. Installed Home app.js and both Helper state-permissions
files matched the verified payload. Both installer receipts were idle.
From Media Player, a single network HOME reached LG Home and held for one
second. Explicit Start used the same Helper launch request as the UI. From
Media Player, one network HOME then passed through LG Home to Clean Your TV
and held there for one second. Ordinary Restore returned the same network
check to LG Home. Ordinary rollback installed published Helper 0.8.6 with
Home 1.18.7. Versions, module hashes, idle receipts and stock network HOME
verified again.

The first routing harness attempt stopped before connecting because the
client was constructed outside the event loop. Moving construction into the
coroutine resolved it. A read-only SSAP firmware request lacked permission;
the installer's read-only SSH service query returned the model and versions.
No Magic Remote, standby, AC boot, audio or OTA test was part of this probe.

The real candidate package and published packages passed
`verify_helper_transition` against the committed compatibility record.
No Homebrew Installer promotion is selected.

The C3 was returned to its initial published Home 1.18.6 and Helper 0.8.5
with idle receipts and stable LG Home routing. The temporary handoff for
an independent media-library check occurred after that readback.
