## Consolidated Root recovery batch

The old candidate refused cleanup of an immutable BSP overlay that setup already
accepted. The exact C1 positive regression returned `route-changed` before
#543. The finalizer now accepts the verified topology while retaining the binary,
device identity and inverse proof checks. The 66-case cleanup suite passed with exact Node 0.12.2 enabled and
one platform skip.

expired launcher readiness window blocked both update and Change Home. #546
adds explicit recovery, archives the original journal and uses the actual
launcher readiness signal. The integrated fix holds the product lease through
the bounded close and launch calls and archives evidence before registration
repair. The contention regression failed before this correction and passed
afterwards. Four rollback readiness tests and 183 CLI and System/installer
tests passed. A live standalone C1 or legacy Updater scenario cannot be inferred
from this C3's completed System journal. The reporter-device results are pending.

(296 setup tests, 1362 installer tests with 119 environment skips, and the
other selected tool checks). The batch payload was rebuilt and verified.
