# v1.30.0 Helper compatibility preflight

The [release PR](https://github.com/Razdva122/clean-your-tv-lg-webos/pull/844)
tracks candidate acceptance. This preflight used a local payload from
`1ea95a6e` plus the proposed v1.30.0 version metadata. It verifies the published
Home and candidate Helper pairing before full dispatch.

Project LG OLED55C3RLA, firmware 43.21.71, webOS SDK 11.2.0. macOS ARM64
cytv 0.25.0 source installer used the saved No-root over Root SSH connection.
Home checks used the paired network remote. The physical remote was not used.

| Case | Expected result | Observation |
| --- | --- | --- |
| P00 preparation | Restore stock routing and finish removing the generation-2 test installation. | No-root removal returned `root-access-required` before submission. The saved Root profile continued full removal. The first Root pass requested a restart for `startup-disable-unverified` and `resident-installer-evidence`. A verified software restart reset uptime and cleared a temporary marker. The original Root removal resumed and reached `verified-clean`. One network HOME from Media Player opened stable LG Home at 0.32 s. |
| P00 compatibility | Install published FHD Home 1.22.0 with candidate Helper 0.11.1. Verify the running Helper and reach stable CYTV Home from Media Player. | The ordinary installer verified package setup and requested launch. Twelve installed Home, Helper and Ambient 0.0.7 files matched their input IPKs. The Helper reported `ready` with a live controller and Home enabled. No pending setup remained. One network HOME from Media Player opened LG Home at 0.29 s, then CYTV Home at 0.86 s. It held for at least one second. |

The published Home 1.22.0 and Helper 0.11.0 hashes were authenticated against
the [v1.29.1 release](https://github.com/Razdva122/clean-your-tv-lg-webos/releases/tag/v1.29.1)
and its signed No-root feed. The installer personalizes Home's app inventory as
part of ordinary installation. The tested Helper 0.11.1 IPK SHA-256 is
`f9571d4ca23aa4ace24a581a72d52b737051481880af13552dd9a0d079be4d8d`.
Its canonical archive SHA-256 is
`b6900c5141e5c3ae8387990a8d2610bd230398da6e11a0fe17502f1b2ad465f3`.
The package-based `verify_helper_transition` check passed against the recorded
compatibility approval.

The older published Home and new Helper pairing remains installed for the
planned final No-root upgrade. Standby, cold boot, audio, physical controls,
Developer Mode, HD and live OTA were untested. This pass used pre-dispatch
packages. Final artifact installation and the remaining scoped release cases
stay open.
