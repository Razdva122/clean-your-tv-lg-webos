## Checks on the project C3

LG OLED55C3RLA, firmware 43.21.71, SDK 11.2.0. No-root Edition installed using
the bundled macOS arm64 CLI and the saved Root SSH transport. Input used the
paired network remote. Physical remote model, audio and physical key behavior
were not verified. Root Edition was not installed from this build.

- The installer verified the package installation and reported that Helper
  required explicit Start. The paired launch request for the standard Start
  action was accepted. Six Home file hashes and six Helper file hashes matched
  the selected FHD artifacts.
- Network Home opened Clean Your TV after a brief LG Home transition from the
  built-in Media Player. The destination remained stable after one second.
  This also worked after waking the TV.
- The first power-off and Wake-on-LAN trials with LG Quick Start+ off returned
  to Live TV. The dedicated boot readback showed uptime reset despite a reused
  boot identifier. The new Helper controller preserved the input under its
  existing automatic startup policy. These observations are full webOS startup
  evidence and do not exercise the targeted same-session standby policy.
- Quick Start+ was enabled temporarily to test the same-session path. With the
  No-root option on, the persisted setting confirmed the choice. The C3 reported
  Active Standby, Suspend and Active. Helper logged `resume-preserved-source`;
  Live TV remained in front and uptime continued.
- With the option off, the same standby sequence opened Clean Your TV from
  Live TV. Helper logged `resume-launch`, the foreground remained stable for
  five seconds, and SSH confirmed the same controller and advancing uptime.
  Quick Start+ was returned to its original Off setting. The No-root input
  option is Off and Home control remains enabled.
