# Фильтрация DNS на телевизоре LG без root

Рекламные и трекинговые домены можно блокировать в домашней сети с любой редакцией CYTV или со штатным экраном LG Home. CYTV не меняет DNS телевизора. Для настройки понадобятся пульт и либо внешний DNS-сервис, либо постоянно включённое устройство в домашней сети.

[English](PRIVACY-DNS.md) · [Приватность в меню телевизора](PRIVACY.ru.md) · [Сетевые обращения CYTV](CYTV-NETWORK.ru.md)

## 1. Подготовьте фильтр

Выберите один вариант. Для начала используйте отдельный профиль или DNS-сервер только для ТВ. Тогда можно будет отменить правило, не затрагивая остальные устройства.

| Вариант | Что настроить |
| --- | --- |
| AdGuard Home в домашней сети | Закрепите за сервером постоянный локальный адрес. В разделе **Фильтры → Чёрные списки DNS** добавьте [список HaGeZi для LG webOS](https://raw.githubusercontent.com/hagezi/dns-blocklists/main/adblock/native.lgwebos.txt) как пользовательский список. Включите его и проверьте, что он загрузился. [Настройка AdGuard Home](https://adguard-dns.io/kb/adguard-home/getting-started/) |
| Pi-hole в домашней сети | Закрепите за Pi-hole постоянный локальный адрес. В разделе **Domains** добавьте по одному точному правилу блокировки на домен. Для начала можно взять рекламный узел LG (`ad.lgappstv.com`) и узел Alphonso (`prov-lg.alphonso.tv`). Если Pi-hole уже обслуживает другие устройства, назначьте правила и телевизор отдельной группе. [Настройка Pi-hole](https://docs.pi-hole.net/main/post-install/) |
| Внешний сервис NextDNS | Создайте профиль для ТВ. В **Denylist** внесите те же два домена по одному. Откройте **Setup** и возьмите адреса из своего профиля. Для обычного IPv4 выполните шаг **Linked IP** и обновляйте привязку при смене внешнего IP домашней сети. NextDNS получает имена запрошенных доменов и ваш внешний IP. В **Settings** выберите срок хранения журнала. [Панель NextDNS](https://my.nextdns.io/) |

## 2. Подключите телевизор к фильтру

1. Сфотографируйте параметры активного подключения. Должны быть видны автоматический режим, IP-адрес, маска, шлюз и DNS. Проверьте, что открываются магазин LG и приложение для просмотра видео.
2. Если роутер позволяет указать DNS для одного устройства, назначьте его телевизору и переподключите ТВ к сети. Изменение общих параметров DHCP затронет и другие устройства. Для настройки с пульта откройте **Все настройки** и выберите путь для установленной версии webOS. [Инструкция LG с иллюстрациями](https://www.lg.com/us/support/help-library/manual-dns-settings-webos-CT10000020-20150576570174)

   | webOS | Меню |
   | --- | --- |
   | 6 и новее (с 2021 года) | Общие → Сеть |
   | 5 (2020) | Подключение → Настройки сетевого подключения |
   | 4.5 (2019) | Подключение |
   | 4 и старше (до 2018 включительно) | Сеть, если этот пункт доступен |

3. Выберите активное проводное подключение или **Подключение к Wi-Fi → Расширенные настройки Wi-Fi**, затем **Изменить**. Если после снятия флажка **Автоматически** адрес ТВ тоже станет ручным, предварительно зарезервируйте его на роутере. Сохраните маску и шлюз. В поле **Сервер DNS** введите адрес фильтра и сохраните настройки. Если такого поля нет, задайте DNS на роутере.
4. Если сеть выдаёт телевизору DNS по IPv6 или дополнительный DNS-сервер, проверьте, что каждый из них применяет те же правила. Изоляция устройств в гостевой сети может прервать связь ТВ с локальным DNS, установщиком или устройством для трансляции.

## 3. Проверьте результат с телевизора и при необходимости верните настройки

Откройте `example.org` **в браузере телевизора**. Найдите запрос в журнале DNS. Временно заблокируйте это точное имя, дождитесь истечения срока кеширования и снова откройте страницу. В журнале должна появиться запись о блокировке. Удалите тестовое правило. Если все запросы приходят с адреса роутера, сопоставьте запись по времени открытия страницы на ТВ. После проверки журнал можно выключить.

Проверьте магазин, воспроизведение видео, вход в аккаунт, часы и поиск обновлений LG. В No-root проверьте таймер Developer Mode и продление сессии, если им пользуетесь. При сбое выключите последнее правило или список, переподключите ТВ и повторите проверку. По журналу можно добавить в исключения только домен, который нужен этой функции. Блокировка доменов целиком, например `lge.com` или `lgtvsdp.com`, может затронуть сразу несколько служб.

Для отката включите **Автоматически**, верните прежние значения с фотографии или отмените правило для ТВ на роутере. Переподключитесь и повторите те же проверки. В журнале DNS видны запросы доменных имён. Приложения с закешированным адресом, прямым подключением по IP или собственным шифрованным DNS могут обходить фильтр.
