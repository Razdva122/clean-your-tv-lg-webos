# v1.23.1

- The installer can resume Root removal when the private Python runtime
  contains generated bytecode for its recorded source files. It still refuses
  unknown files and requires verified cleanup. The original C1 removal has
  not been confirmed on the reporting TV (#689, #389).
- Root Home recovery preserves a verified active route when the recovery
  activity runs again in the same boot. It still restores stock routing for
  unverified or interrupted state and does not re-enable a stopped filter.
  The reporting A1 has not been retested (#690, #615).
- No-root Debloat explains when the TV explicitly rejects a setting change.
  This does not change TV permissions or resolve the separate Home routing
  report (#691, #687).
