# Alpine 1.4.4

Maintained Showcase source imported from
`https://github.com/razdva122/clean-your-tv-lg-theme` commit
`95f812e505e81b1d4b706bd203f0e96306b1b18c`, `examples/glasshouse`.
The canonical identity is now `github:razdva122/clean-your-tv-lg-webos:alpine`.
CSS, layout, all eight assets, LICENSE and CREDITS retain the exact 1.4.4 bytes.
This is not the archived external Alpine 1.4.2 distribution.

Alpine is no longer a bundled choice. An existing `builtin:alpine` selection
uses the normal missing-theme recovery: restore Classic, clear only the theme
choice/recovery marker and show the recovery notice. Other saved preferences
remain. There is no automatic download or substitution with Liquid Glass.
To use Alpine again, select its reviewed Showcase listing and explicitly install
and accept it through the ordinary theme flow. Cached external themes retain
their existing identities and bytes.

Before publishing the Showcase record, commit the source, generate the ordinary
Theme API 1 distribution with that exact source identity, commit/push those
distribution bytes and pin their immutable descriptor URL and SHA-256. Local
source/preview work alone does not publish the theme or prove physical TV
compatibility.

Next-release source 1.5.0 replaces the panorama with Friedrich-Karl Mohr’s real 6000×4000 Bachalpsee photograph, cropped/downsampled without upscaling. It embeds a native UHD still-video loop, an FHD loop and a UHD JPEG fallback. The historical published 1.4.4 distribution stays unchanged. See CREDITS.txt, LICENSE.txt and wallpaper-preparation.json for rights and preparation.
